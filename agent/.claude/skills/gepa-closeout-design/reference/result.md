## 0. 조사 범위와 방법

| 단계 | 내용 | 규모 |
|---|---|---|
| 모집단 추출 | 제목에 `결과보고/결과 보고/결과 및/추진결과/운영 결과/결과보고서/사업결과` 포함 + **비완료 보고 제외**(접수·선정·평가·심사·현장점검·출장·모집·정산결과 통보·반납·계약·입찰·회신·요청·안내·품평회·실사·중간보고·준공·청렴/인권/소방 등 내부관리) | 385건 |
| 중복 제거 | 시군별 동일 문서(예: 아이보듬 21개 시군, 경영혁신 외식 14개 시군), (수정)본 제거 → **사업 계열 단위** | **266건** (A 151 / B 93 / C 21 / 판별불가 1) |
| 정량 분석 | 266건 전체에 대해 장(章) 제목 추출, 슬롯 매핑, 표기 관례 정규식 집계 | 244건(A+B) 기준 빈도 |
| 정독(close reading) | 8개 팀 × 6개 사업유형에서 **58건** 본문·붙임 결과보고서 직접 판독 | 표 0-1 |

문서 형태 정의(이하 계속 사용):
- **A형 — 내부결재 보고서형**: 본문(Body) 자체가 보고서. 1쪽 = 전자결재 표지(등록번호·결재란·제목), 2쪽부터 개조식 보고서. 수신 없음.
- **B형 — 대외 제출 기안문 + 붙임 결과보고서**: 1쪽짜리 기안문(수신: 경상북도지사(○○과장) / ○○시장(○○과장))에 `결과보고서`·`정산보고서`·`통장거래내역`·`증빙(별송)`을 붙임.
- **C형 — 기안문 본문형**: 1~2쪽 기안문 본문에 `가. 나. 다.` 항목으로 결과를 바로 기재(소규모 행사·설명회, 간단한 시군 회신).

## 10. 생성 시스템 구현 메모

1. **템플릿 선택 로직**: 사업유형(M1~M8) × 형태(A/B/C) × 결과요약 사용여부(연간 지원사업=예).
2. **자동 계산**: 합계, 평균, 비중(%), 달성률, 경쟁률, 전년 대비 %↑↓, 집행률(소수 2자리), 한글 금액(`금이억원`), 천원·백만원·천USD 환산.
3. **문체 검증기**: 문장 종결 `함/음/임/필요/예정/명사` 외 금지, 한 문서 내 세부기호 1종, 날짜 `YYYY. M. D.(요일)`, 금액 콤마, `천달러` → `천USD` 치환, `끝.` 위치 규칙(5-4).
4. **분량 가드**: 본문 5~10쪽 권장, 기업별 상담내용은 기업당 3~5개 `-` 이내, 총평 3~5개 항목.
5. **추출 잡음 주의(학습 데이터 정제)**: PDF 추출본의 이중 글자(`사사업업개개요요`), 반복된 로마숫자(`ⅠⅠⅠⅠ`), 번호박스 이중숫자(`11 전시 개요`), 2쪽 모아찍기(538 `- 2 - - 3 -`), 균등배분 자간 깨짐(`사 명: 업`)은 원문 서식 효과이므로 학습 예시로 쓸 때 반드시 정서할 것. 스캔본(만족도·서명부·상담일지)은 텍스트 없음.
