# GEPA 정산·결과보고 작성 규격

근거: 2026년 GEPA 실문서 조사(정산 449건·결과보고 385건·커버 공문 457건).
- `reference/settlement.md` — 정산보고서 서식 변형·계산 규칙·비목 사전·잔액사유 문형
- `reference/result.md` — 결과보고서 골격·유형 모듈 M1~M9·개조식 규칙·실제 예시 3건
- `reference/cover.md` — 커버 공문 골격·수신·제목·정산표 열 이름

## 0. 숫자는 쓰지 않는다 — 원장과 매크로가 쓴다

이 프로젝트의 **모든 금액·합계·집행률·잔액·반납액은 프로그램이 계산한다.** 실제 정산보고서 449건 가운데 합계가
안 맞는 문서가 여럿 나왔다(예: 세부내역 349,800 ↔ 통장 329,800). 그래서:

1. 정산자료 단계는 원자료의 숫자를 `ledger/ledger.json` 에 **옮겨 적기만** 한다(더하거나 나누지 않는다).
2. 플랫폼이 원장을 계산해 `ledger/summary.md` 를 쓴다 — 검증 결과, 핵심 수치, 표 미리보기가 있다.
3. 문서 단계는 정산 표를 **매크로 한 줄**로 넣는다. 저장할 때 계산된 표로 펼쳐진다.
4. 본문 문장 속 금액도 매크로로 쓴다: `사업예산: {{정산:예산액한글}}` → `금20,000,000원(금이천만원)`.

| 표 매크로(한 줄 단독) | 펼쳐지는 것 |
|---|---|
| `{{정산:총괄표}}` | (단위 : 원, %) 구분·예산액·지출액(금액·비율)·집행잔액·이자발생액·반납액 — 계/재원/자부담 행 |
| `{{정산:항목별}}` | 비목군·세목별 예산액·집행액·집행잔액, 소계, 합계 |
| `{{정산:세부내역}}` | 일자·인출액·비목·내역·지급처·번호·지급방법 + 계 + 증빙 별도 편철 각주 |
| `{{정산:변경내역}}` | 당초예산≠예산인 세목(없으면 "해 당 없 음") + 승인여부 각주 |
| `{{정산:잔액사유}}` | 합계 + 비목군별 예산·지출·잔액·발생사유 + 발생사유 각주 |
| `{{정산:공문표}}` / `{{정산:공문표 열=통장잔액}}` | 교부금(A)·집행액(B)·잔액(C)·예금이자(D)·반납액(통장잔액)(C)+(D) |

| 값 매크로(줄 안) | 예 |
|---|---|
| `{{정산:사업명}}` `{{정산:사업기간}}` `{{정산:재원명}}` | 원장의 값 |
| `{{정산:예산액}}` `{{정산:예산액한글}}` `{{정산:예산액천원}}` | 20,000,000 / 금20,000,000원(금이천만원) / 20,000천원 |
| `{{정산:집행액}}` `{{정산:집행액한글}}` `{{정산:집행률}}` | 18,319,100 / … / 91.59% |
| `{{정산:집행잔액}}` `{{정산:이자}}` `{{정산:반납액}}` `{{정산:반납액한글}}` | 1,680,900 / 10,357 / 1,691,257 / … |

**표를 손으로 만들지 않는다.** 위 표에 없는 모양(예: 업체별 지원내역, 상담실적)은 원자료의 숫자를 **그대로 옮긴** 표로
만들 수 있다 — 그때도 합계는 원자료에 적힌 합계를 옮기고, 직접 더하지 않는다(원자료에 합계가 없으면 합계 행을 두지 않는다).

**자료에 없는 사실은 쓰지 않는다.** 날짜·인원·기업명·상담액·만족도가 자료와 메모에 없으면 지어내지 말고 그 줄을 빼거나
`○○` 자리표시로 남긴다(담당자가 결재 전에 채운다). 연도를 옮겨 붙이지 않는다 — 2025년 사업의 실적은 2025년 실적이다.

## 1. 정산자료 단계 — ledger.json

먼저 `materials/index.md` 를 읽고 각 자료를 읽는다(`text` 는 옮긴 텍스트, `direct` 는 원본을 Read). 그다음
`ledger/ledger.json` 을 쓴다.

```json
{
  "사업명": "2025년 서비스산업 투자유치협의체",
  "사업기간": "2025. 2. ~ 12.",
  "시작일": "2025-02-01", "종료일": "2025-12-31",
  "재원명": "위탁사업비",
  "재원": [{ "이름": "위탁사업비", "예산": 20000000 }],
  "자부담": 0,
  "예산": [
    { "비목군": "사업비", "세목": "행사운영비", "예산": 17281600, "잔액사유": "집행잔액" },
    { "비목군": "사업비", "세목": "회의비", "예산": 300000 },
    { "비목군": "운영비", "세목": "국내여비", "예산": 778400, "잔액사유": "실비 정산에 따른 잔액" },
    { "비목군": "수수료", "세목": "대행수수료", "예산": 1640000 }
  ],
  "집행": [
    { "일자": "2025-04-07", "금액": 4250000, "세목": "행사운영비", "내역": "킥오프 회의 행사장 대관 및 오찬 비용 지급",
      "지급처": "글래드호텔앤리조트(주)", "지출번호": 1, "지급방법": "카드", "출처": "집행내역.xlsx 시트1 5행" }
  ],
  "이자": [{ "일자": "2025-06-29", "금액": 4919 }, { "일자": "2025-12-28", "금액": 5438 }],
  "결산세": 0,
  "통장최종잔액": 1691257,
  "반납원단위절사": false,
  "메모": ["통장 12-02 이희우 329,800 — 집계표의 349,800 은 오기로 보고 통장 금액을 씀"]
}
```

규칙
- **금액은 원 단위 정수.** 콤마·"원"을 빼고 적는다. 여입·반환은 음수.
- **비목군**은 `사업비 | 운영비 | 인건비 | 수수료` 넷 중 하나. 세목→비목군은 **교부결정서·사업계획서 예산표를 따른다**
  (회의비처럼 사업마다 갈리는 세목이 있다). 예산표가 없으면 아래 사전의 기본값을 쓰고 `메모`에 적는다.
  - 사업비: 민간사업지원금·기업지원금, 행사운영비, 일반용역비, 홍보비, 물류비, 통역비, 교육훈련비, 컨설팅수당, 전산개발비
  - 운영비: 사무관리비(심사수당·사무용품·회계검토), 국내여비, 국외업무여비, 회의비, 공공운영비
  - 인건비: 전담인력 인건비, 파견용역비
  - 수수료: 대행수수료·위탁수수료·운영수수료
- **세목 이름은 예산과 집행에서 같아야 한다**(예산에 없는 세목의 지출은 오류로 잡힌다).
- **재원 합계 = 세목 예산 합계** 여야 한다. 도비·시군비처럼 둘 이상이면 각각 적는다(안분은 프로그램이 한다).
- 집행 건: 집행 집계표·지출결의가 있으면 그것을 기준으로 세목·내역을 쓰고, 통장거래내역으로 일자·지급처·금액을 대조한다.
  둘이 다르면 통장을 따르고 `메모`에 남긴다. **교부금 입금·이자 입금·반납 출금은 집행이 아니다.**
- 같은 결의로 여러 명에게 나눠 지급하면 건을 나누고 지출번호를 같게 둔다.
- 이자: 통장의 이자 입금(결산이자·예금이자) 건별. 결산 법인세·지방세가 원천징수되었으면 `결산세`에 합계.
- `통장최종잔액`: 통장거래내역의 마지막 잔액(있을 때만). 프로그램이 `집행잔액+이자`와 대조한다.
- `잔액사유`는 잔액이 생긴 세목에만 [원인]+[결과] 한 줄 명사형: "선정기업 2개사 사업포기에 따른 지원금 잔액",
  "회의비·여비 실비 정산에 따른 잔액", "지급사유 미발생". 1만원 미만이면 "집행잔액".
- 변경 승인이 있었으면 그 세목에 `당초예산`·`변경사유`("기업별 지원인원 확정에 따른 감액")·`승인`("경상북도 승인" | "○○시 승인" | "자체변경")을 적는다.
- `출처`에 파일·시트·행을 남긴다(검토자가 되짚는다). 확신이 없는 대응은 모두 `메모`에 적는다.

## 2. 결과보고서 (family: plan — 내부결재 보고서형)

```yaml
---
family: plan
제목: 「2025년 서비스산업 투자유치협의체」 결과보고
부서: ESG·기업지원팀
결재: { 공개구분: 공개 }
numbering: roman
lineSpacing: 160
body1Font: hyHeadlineBold
---
```
결재란·표지는 작성기가 만든다(부서로 결재라인이 정해진다). 본문 골격(장 5개 고정 + 유형 모듈):

````markdown
```box
◇ (요지) 서비스산업 분야별 전문가 협의체를 구성·운영하여 투자유치 플랫폼 구축
◇ (핵심 수치) 투자유치 회의 3회, 위원 22명, 예산 {{정산:예산액천원}} 중 {{정산:집행률}} 집행
```
# 사업개요
□ 추진배경 및 목적
ㅇ …(사업계획서에서 옮김, 1~3줄)
□ 사업개요
ㅇ 사 업 명: 「{{정산:사업명}}」
ㅇ 사업기간: {{정산:사업기간}}
ㅇ 사업예산: {{정산:예산액한글}}
ㅇ 주요내용: …
# 추진결과
□ 추진결과 요약
(유형 모듈의 요약표)
□ 세부 추진결과
(회차별·기업별·국가별 블록)
# 주요성과
□ 정량 성과  ← 목표가 자료에 있을 때만 지표명|목표|실적|달성률
□ 정성 성과
# 예산 집행 현황
{{정산:항목별}}
※ 집행잔액 {{정산:집행잔액}}원, 예금이자 {{정산:이자}}원 반납 예정
# 총평 및 향후계획
□ 총평
ㅇ …함
□ 개선사항
ㅇ (문제) … → (개선) … 필요
□ 향후계획
ㅇ … 예정
```attach
붙임 1. ○○○ 1부.
```
````

장 이름은 유형에 맞게 바꿀 수 있다: Ⅰ 행사개요/전시 개요/교육개요, Ⅱ 세부 추진결과/주요 실적, Ⅲ 사업성과 및 발전방안.
Ⅲ 성과 서술이 3줄 이하면 Ⅴ 총평에 흡수한다. 분량 5~10쪽.

유형 모듈(자세한 표 열은 `reference/result.md` §4):
- **M1 행사·회의·협의체**: Ⅰ에 구성 개요(임기·구성·주요기능·운영방법), 추진결과 요약표 `구분|일시|장소|참석규모|주요내용`,
  Ⅱ 회차별 `## 회의명` + `ㅇ 일    시:` `ㅇ 장    소:` `ㅇ 참석인원:` `ㅇ 주요내용:` `ㅇ 주요 논의사항` + `-` 나열, 행사시간표 `시간|주요내용|비고`.
- **M2 교육**: 교육개요(교 육 명·연 사 진·일 시·장 소·대 상·참 석 자), 커리큘럼표 `시간|연사진|주제|비고`, 수료 실적, 만족도.
- **M3 기업 지원금·바우처·시군위탁**: 지원내용표, 추진절차 ```` ```flow ````, 추진경과(공고·접수·선정·현장점검·지급),
  지원현황 총괄 `모집규모|신청현황|선정현황|지원현황|비고`, 업체별 지원내역 `No.|회사명|추진항목|지원금액|비고`.
- **M4 소상공인 대량지원**: 신청·지급·탈락표, 시군별·매출구간별·업종별 분석표 + 해석 1~2줄, 연도별 비교.
- **M5 해외전시·무역사절단·공동관**: 요지 박스를 KPI 4줄로(❖ 참가규모·상담건수·상담금액(천USD)·계약추진액),
  참가기업 목록, 상담 실적 총괄, 기업별 상담 실적, 기업별 주요 상담 내용(2열 표). 외화는 **천USD**(천달러 금지).
- **M6 국내 판로**: 총괄(운영기간·매출액·방문객), 기업별 판매 현황.
- **M7 제작물**: 제작 개요, 제작수량, 배포처표.
- **M8 일자리**: 목표 대비 실적표 `지표명|목표|실적|달성률` + "○ 목표 대비 ○ 달성하여 ○% 달성".

개조식 규칙: 기호 `□ → ㅇ → - → ·`, 주석 `※`. 종결은 `~함/~음/~임`과 명사 종결(`~필요`, `~예정`, `~도모`, `~기여`).
`~했다/~합니다` 금지. 성과 문장 = (무엇을) + (얼마나: 수치) + (효과). 날짜 `2025. 5. 26.(월)`, 금액(개요) `금○원(금○원)`.
항목명 두·세 글자는 4자 폭으로 띄운다(`사 업 명`, `일    시`). 근사치는 `정도`.

## 3. 정산보고서 (family: plan, 표지: 없음 — 위탁사업 추진실적 및 정산보고서)

위탁기관이 정한 서식이라 결재란이 없다. **아래 틀을 그대로 쓰고 서술 칸만 채운다.**
`{재원명}`(위탁사업비·보조금·지방보조금·출연금)은 원장의 재원명과 같게 쓴다. `□` 는 큰 제목 글씨로 나가므로
이 서식의 절 안 항목은 **`ㅇ`** 로 쓴다.


## 4. 제출 공문 (family: official — 별지 제1호 기안문)

front-matter 는 `gepa-official-design` 규격 그대로(수신유형: 수신자, 수신: 프로젝트의 수신, 처리과, 전결, 연락처, 공개구분).
제목: `「{사업명}」 결과 및 정산보고` (실문서 최빈 — "정산 및 결과보고"보다 6배 많다). 붙임은 front-matter 의 붙임 목록에.

```
1. {인사말}
   수신이 경상북도 → "경상북도의 무궁한 발전을 기원합니다."
   수신이 시·군   → "귀 기관의 무궁한 발전을 기원합니다."
2. 「{사업명}」 사업 추진이 완료됨에 따라 결과 및 정산 내역을 다음과 같이 보고합니다.
  가. 사업개요
    1) 사 업 명: {{정산:사업명}}
    2) 사업기간: {{정산:사업기간}}
    3) 사업내용: (한 줄)
    4) 사업예산: {{정산:예산액한글}}
    5) 추진실적: (한 줄 — 결과보고서 요지)
  나. 정산내역
    1) 반납액: {{정산:반납액한글}}          ← 수신이 도이면 "통장잔액"
    2) 세부내역
{{정산:공문표}}                             ← 수신이 도이면 {{정산:공문표 열=통장잔액}}
붙임: [정산보고서 1부., 결과보고서 1부., 통장 거래내역 1부., 지출증빙자료 1식(별송).]
```

- `1.` `2.` 번호는 **직접 적는다**(작성기가 매기지 않는다). 실문서는 모두 `1. 인사말` `2. 보고 문장` 으로 시작한다.
- 반납 계좌·기한은 쓰지 않는다(교부기관이 정산을 확정하며 통보한다 — 실문서 457건 중 2건뿐).
- 시행번호·접수번호는 만들지 않는다.
