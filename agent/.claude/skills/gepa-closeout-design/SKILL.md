# GEPA 정산·결과보고 작성 규격

근거: 2026년 GEPA 실문서 조사(정산 449건·결과보고 385건·커버 공문 457건).
- `reference/settlement.md` — 정산보고서 서식 변형·계산 규칙·비목 사전·잔액사유 문형
- `reference/result.md` — 결과보고서 골격·유형 모듈 M1~M9·개조식 규칙·실제 예시 3건
- `reference/cover.md` — 커버 공문 골격·수신·제목·정산표 열 이름
- `reference/result-writing.md` — 결과보고서 문장 쓰는 법: 자리별 좋은 예문(실문서 36건 정독, 2026-10-21 결과보고 251건 재조사로 우수사례 §1-8·전년 대비 표 §1-9·개선사항 H-2/H-3 추가)·흔한 약점과 고친 예·성과지표 대조(§2-1 의 근거)
- `reference/gov-manual.md` — 행정업무운영 편람(2025)의 공문서 작성 기준: 날짜·금액·쌍점·물결표 표기, 항목 기호, 끝 표시. **쓰기 전에 §2·§3 을 읽는다.**

## 대원칙

**공문서는 간결해야 하며 장황해서는 안 된다. 꼭 필요한 것이 절대 누락되지 않고, 없어야 할 것이 절대 들어가서는 안 된다.**(담당자 2026-10-21)
결과보고서의 뼈대는 사업계획(안)이다 — 계획서의 ◇ 요지, 사업내용의 분야·세부사업 위계와 순서, 추진절차·선정방법 문장을 성과 분석 메모 §0-1 에 그대로 옮기고, 결과보고서는 그 골격 위에 실적을 얹는다.
**지면은 중요도에 비례한다.** 결과보고서에서 중요한 것은 계획 대비 무엇을 했고 무엇이 달라졌는지, 다음에 무엇을 바꿀지다. 절차·경위·행정 세부에 지면을 쓰지 않는다.
아래 모든 규칙은 이 원칙을 지키기 위한 것이다. 규칙끼리 부딪치면 이 원칙을 따른다.

## 공문서 기본 틀

결과·정산보고도 공문서다. 문체·머리말·나란한 항목·표기 규칙은 작업장 공통 지침(`CLAUDE.md` 「공문서 기본 틀」)을 따른다 —
개조식 명사형 종결, 머리말 줄에 다른 괄호 금지, 번호와 괄호 머리말 섞지 않기, 나란한 항목 한 줄, 개수 대신 목표·실적 한 쌍.

## 0. 숫자는 쓰지 않는다 — 원장과 매크로가 쓴다

이 프로젝트의 **모든 금액·합계·집행률·잔액·반납액은 프로그램이 계산한다.** 실제 정산보고서 449건 가운데 합계가
안 맞는 문서가 여럿 나왔다(예: 세부내역 349,800 ↔ 통장 329,800). 그래서:

1. 정산자료 단계는 원자료의 숫자를 `ledger/ledger.json` 에 **옮겨 적기만** 한다(더하거나 나누지 않는다).
2. 플랫폼이 원장을 계산해 `ledger/summary.md` 를 쓴다 — 검증 결과, 핵심 수치, 표 미리보기가 있다.
3. 문서 단계는 정산 표를 **매크로 한 줄**로 넣는다. 저장할 때 계산된 표로 펼쳐진다.
4. 본문 문장 속 금액도 매크로로 쓴다: `사업예산: {{정산:예산액한글}}` → `금20,000,000원(금이천만원)`.

| 표 매크로(한 줄 단독) | 펼쳐지는 것 |
|---|---|
| `{{정산:총괄표}}` | (단위 : 원, %) 구분·예산액·지출액(금액·비율)·집행잔액·이자발생액·비고 — 계/재원 행(자부담 있을 때만 그 행) |
| `{{정산:집행현황}}` | 시간순 전체 집행: 지출일자(05.20.)·지출액·비목(사업비(민간사업지원금))·내역·지급처·지출번호·지급방법 + 계 |
| `{{정산:항목별}}` | 비목군별 당초예산(변경전)·최종예산(변경후)·실제 집행액·잔액 + 합계 |
| `{{정산:세부내역}}` | 예산 줄(세부사업·세목)마다 "❍ (사업비) 세부사업명(집행액: N원)" 머리 + 그 줄의 집행 표 |
| `{{정산:세부사업별}}` | 결과보고서 Ⅲ — 세부사업(예산 줄)별 당초예산·최종예산·집행액·잔액 + 합계 |
| `{{정산:기업별 세부사업="세부사업 이름"}}` | 그 세부사업의 기업별 지원 현황 — 연번·기업명·(지원항목)·지원내용·지원금액 + 합계. 지급처별로 묶고(추가 지급은 더함) 지원항목·지원내용은 원장 집행 건의 값. 세부사업이 없는 사업은 `{{정산:기업별}}`, 지원금 세목 이름에 "지원금"이 없으면 `세목=…` 을 더한다 |
| `{{정산:변경내역}}` | 당초예산≠예산인 줄: 항목(세부사업)·비목·당초예산·변경예산·주요 변경사유·승인여부(없으면 "해 당 없 음") |
| `{{정산:잔액사유}}` | 합계 + 비목군별 예산·지출·잔액·발생사유(서식이 요구할 때만) |
| `{{정산:공문표}}` | 교부금 Ⓐ·집행액 Ⓑ·사업비잔액 Ⓒ=Ⓐ-Ⓑ·예금이자 Ⓓ·통장잔액 Ⓒ+Ⓓ (`열=반납액` 이면 마지막 열 이름만 반납액) |

| 값 매크로(줄 안) | 예 |
|---|---|
| `{{정산:사업명}}` `{{정산:사업기간}}` `{{정산:재원명}}` | 원장의 값 |
| `{{정산:예산액}}` `{{정산:예산액한글}}` `{{정산:예산액천원}}` | 20,000,000 / 금20,000,000원(금이천만원) / 20,000천원 |
| `{{정산:집행액}}` `{{정산:집행액한글}}` `{{정산:집행률}}` | 18,319,100 / … / 91.59% |
| `{{정산:집행잔액}}` `{{정산:이자}}` `{{정산:반납액}}` `{{정산:반납액한글}}` | 1,680,900 / 10,357 / 1,691,257 / … |

**표를 손으로 만들지 않는다.** 기업별 지원금 표는 `{{정산:기업별 …}}` 로 넣는다. 위 표에 없는 모양(예: 지정기업 목록, 상담실적)은 원자료의 숫자를 **그대로 옮긴** 표로
만들 수 있다 — 그때도 합계는 원자료에 적힌 합계를 옮기고, 직접 더하지 않는다(원자료에 합계가 없으면 합계 행을 두지 않는다).

**금액을 직접 더하거나 빼지 않는다.** "10개사에 93,659천원 지원", "2,200천원 감액"처럼 여러 건을 합하거나 두 값의 차를 낸 금액은
본문에 쓰지 않는다 — 합계·차액이 필요하면 매크로 표가 보여 준다. 문장에는 건수·기업 수와 매크로 값(`{{정산:집행률}}` 등)만 쓴다.
내보낼 때 시스템이 문서의 모든 금액을 원장과 대조해, 원장에서 나오지 않는 금액을 「경고」로 띄운다(사업계획서의 지원 한도처럼 원자료에서 옮긴 값은 경고가 떠도 그대로 둔다).

**자료에 없는 사실은 쓰지 않는다.** 날짜·인원·기업명·상담액·만족도가 자료와 메모에 없으면 지어내지 말고 그 줄을 빼거나
`○○` 자리표시로 남긴다(담당자가 결재 전에 채운다). 연도를 옮겨 붙이지 않는다 — 2025년 사업의 실적은 2025년 실적이다.

## 0-1. 줄·쪽 끝을 생각하며 쓴다 (담당자 2026-10-12)

시스템이 내보낼 때 줄 맞춤을 한다: 글머리 다음 첫 글자 아래로 내어쓰기(Shift+Tab), 쪼개진 단어·끝줄 두세 글자는 자간을 줄여 윗줄로(Alt+Shift+N), 쪽 아래 큰 여백은 줄 간격으로 채우기. 그래도 **글이 그렇게 맞을 수 있게 써야 한다** — 자간 조정은 -10 %까지만이다.
- **본문 한 줄은 약 38자, 두 줄은 약 76자**(13~15pt). 한두 글자가 다음 줄로 넘어갈 것 같으면 낱말을 줄여 한 줄로 쓴다 — `※ 목표 5개사, 5개사 지원으로 100% 달성`.
- **빈칸 없이 긴 덩어리를 만들지 않는다.** `네트워킹(지원기업·유관기관·도민 등 약 80명)` 처럼 괄호·가운뎃점으로 이어 붙인 15자 넘는 덩어리는 줄 끝에서 통째로 넘어가거나 쪼개진다. 괄호 앞을 띄우거나(`네트워킹 (참석 약 80명)`) 괄호 안을 줄인다.
- **표 칸 글은 칸 너비에 맞춰 짧게.** 좁은 칸(비고·지급처)은 한 줄 7~8자 안팎 — 기관명은 칸에 들어가게 줄여 쓴다(`(재)경상북도경제진흥원` → `경제진흥원`이 허용되는 칸이면 줄인다).
- 쪽 끝에 제목만 남거나 표 아래가 크게 비는 것은 시스템이 넘김·채움으로 처리한다 — 그것을 피하려고 내용을 지어내지 않는다.

## 1. 정산자료 단계 — ledger.json

먼저 `materials/index.md` 를 읽고 각 자료를 읽는다(`text` 는 옮긴 텍스트, `direct` 는 원본을 Read). 그다음
`ledger/ledger.json` 을 쓴다.

```json
{
  "사업명": "2025년 서비스산업 투자유치협의체",
  "사업기간": "2025. 2. ~ 12.",
  "시작일": "2025-02-01", "종료일": "2025-12-31",
  "재원명": "위탁사업비",
  "재원": [{ "이름": "위탁사업비", "예산": 20000000 }],
  "자부담": 0,
  "예산": [
    { "비목군": "사업비", "세목": "행사운영비", "예산": 17281600, "잔액사유": "집행잔액" },
    { "비목군": "사업비", "세목": "회의비", "예산": 300000 },
    { "비목군": "운영비", "세목": "국내여비", "예산": 778400, "잔액사유": "실비 정산에 따른 잔액" },
    { "비목군": "수수료", "세목": "대행수수료", "예산": 1640000 }
  ],
  "집행": [
    { "일자": "2025-04-07", "금액": 4250000, "세목": "행사운영비", "내역": "킥오프 회의 대관비",
      "지급처": "글래드호텔앤리조트(주)", "지출번호": 1, "지급방법": "카드", "출처": "집행내역.xlsx 시트1 5행" },
    { "일자": "2025-11-20", "금액": 10000000, "세부사업": "기술혁신 역량 강화 지원사업", "세목": "민간사업지원금", "내역": "지원금 지급",
      "지급처": "천일제면㈜", "지원항목": "사업화(R&D)", "지원내용": "생면 생산 자동화 공급 로봇 도입", "지출번호": 14, "지급방법": "계좌이체" }
  ],
  "이자": [{ "일자": "2025-06-29", "금액": 4919 }, { "일자": "2025-12-28", "금액": 5438 }],
  "결산세": 0,
  "통장최종잔액": 1691257,
  "반납원단위절사": false,
  "메모": ["통장 12-02 이희우 329,800 — 집계표의 349,800 은 오기로 보고 통장 금액을 씀"]

```

규칙
- **금액은 원 단위 정수.** 콤마·"원"을 빼고 적는다. 여입·반환은 음수.
- **비목군**은 `사업비 | 운영비 | 인건비 | 수수료` 넷 중 하나. 세목→비목군은 **교부결정서·사업계획서 예산표를 따른다**
  (회의비처럼 사업마다 갈리는 세목이 있다). 예산표가 없으면 아래 사전의 기본값을 쓰고 `메모`에 적는다.
  - 사업비: 민간사업지원금·기업지원금, 행사운영비, 일반용역비, 홍보비, 물류비, 통역비, 교육훈련비, 컨설팅수당, 전산개발비
  - 운영비: 사무관리비(심사수당·사무용품·회계검토), 국내여비, 국외업무여비, 회의비, 공공운영비
  - 인건비: 전담인력 인건비, 파견용역비
  - 수수료: 대행수수료·위탁수수료·운영수수료
- **세목 이름은 예산과 집행에서 같아야 한다**(예산에 없는 세목의 지출은 오류로 잡힌다).
- **세부사업**: 사업이 여러 세부사업(단위사업)으로 나뉘면 예산 줄마다 `"세부사업"` 을 적는다
  (예: 신규선정·체험 프로그램 운영·기술혁신 역량 강화 지원사업). 같은 세목이 여러 세부사업에 있으면
  (민간사업지원금이 기술혁신·디자인·마케팅에 각각) 그 지출에도 `"세부사업"` 을 적어야 한다 — 지원기업 명단·
  선정 결과·지급 공문으로 어느 세부사업인지 정한다. 운영비·수수료처럼 세부사업이 없는 줄은 비운다.
  같은 세목이라도 세부사업이 다르면 다른 줄이다(사업비(사무관리비)=신규선정 인증패, 운영비(사무관리비)=복사용지).
- **비목군명칭·비목칸**: 비목군 값(계산용)은 언제나 사업비·운영비·인건비·수수료 넷 중 하나로 두되, **사업계획서 예산표가 부르는 이름**이
  다르면 표기만 바꾼다. 예산표가 "직접비·간접비"로 나누면 `"비목군명칭": { "사업비": "직접비", "운영비": "간접비" }`,
  예산표·집행 엑셀의 비목 열 이름이 "통계목"이면 `"비목칸": "통계목"`(집행 표 비목 칸에 세목만 적는다). 같은 사업이라도 해마다·담당자마다
  다르므로(고령군 2024 정산은 사업비·운영비, 2025 는 직접비·간접비) **그 해 사업계획서**를 따른다 — 전년도 정산보고서를 따르지 않는다.
- **재원명**: 도·시군이 진흥원에 맡긴 사업(위탁사업)은 `"위탁사업비"`, 보조사업은 `"보조금"`/`"지방보조금"`, 출연금 사업은 `"출연금"` —
  돈의 출처(도비·시비)가 아니라 **정산 서식이 부르는 이름**이다. 출처가 둘 이상이면 `재원` 배열의 이름을 "도비"·"시군비"로 나눈다
  (재원이 하나면 재원 이름도 재원명과 같게 둔다).
- **재원 합계 = 세목 예산 합계** 여야 한다. 도비·시군비처럼 둘 이상이면 각각 적는다(안분은 프로그램이 한다).
- 집행 건: 집행 집계표·지출결의가 있으면 그것을 기준으로 세목·내역을 쓰고, 통장거래내역으로 일자·지급처·금액을 대조한다.
  둘이 다르면 통장을 따르고 `메모`에 남긴다. **교부금 입금·이자 입금·반납 출금은 집행이 아니다.**
- **`내역`은 짧은 명사구(10자 안팎)** 로 쓴다: "지원금 지급", "5월 여비", "복사용지 구입", "도메인 사용료", "심사자료 제작",
  "프로그램 운영 용역비", "신규기업 인증패 제작". 세부사업 이름·기업명·"…지원사업"은 넣지 않는다 — 세부사업은
  `세부사업` 칸과 세부내역 머리(❍)가, 기업은 `지급처`가 이미 보여 준다. 길게 쓰면 집행 표 행이 세 줄로 불어 1쪽 표가 2쪽이 된다.
- **기업 지원금 지급 건**에는 `지원항목`(짧게: "사업화(R&D)", "포장재 제작")과 `지원내용`(무엇을 했는지 20자 안팎: "생면 생산 자동화 공급 로봇 도입")을
  그 기업의 지급 공문·결과보고서에서 옮겨 적는다. 결과보고서·정산보고서의 기업별 지원 현황 표(`{{정산:기업별}}`)가 이 값으로 만들어진다.
  확인할 수 없으면 비워 둔다(표에 ○○ 로 나간다). 지원항목 구분이 없는 사업은 `지원항목`을 쓰지 않는다.
- `지출번호`: 지출결의·증빙 파일 이름이 번호로 시작하면("10. ○○ 지원금 지급.pdf") 그 번호를 쓴다(증빙철 번호와 맞춘다).
  번호가 없을 때만 통장 거래 순서대로 1부터 매기고 `메모`에 적는다.
- 같은 결의로 여러 명에게 나눠 지급하면 건을 나누고 지출번호를 같게 둔다.
- 이자: 통장의 이자 입금(결산이자·예금이자) 건별. 결산 법인세·지방세가 원천징수되었으면 `결산세`에 합계.
- `통장최종잔액`: 통장거래내역의 마지막 잔액(있을 때만). 프로그램이 `집행잔액+이자`와 대조한다.
- `잔액사유`는 잔액이 생긴 세목에만 [원인]+[결과] 한 줄 명사형: "선정기업 2개사 사업포기에 따른 지원금 잔액",
  "회의비·여비 실비 정산에 따른 잔액", "지급사유 미발생". 1만원 미만이면 "집행잔액".
- 변경 승인이 있었으면 그 세목에 `당초예산`·`변경사유`("기업별 지원인원 확정에 따른 감액")·`승인`("경상북도 승인" | "○○시 승인" | "자체변경")을 적는다.
- `출처`에 파일·시트·행을 남긴다(검토자가 되짚는다). 확신이 없는 대응은 모두 `메모`에 적는다.

- **성과는 산출과 결과를 나눈다.** 산출(몇 곳·몇 회)은 실적이고, 성과는 그 결과 확인된 변화다. 결과가 확인되지 않으면 "결과 미확인"과 확인 방법을 적는다 — 결과보고서에서는 성과 자리에 쓰지 않고 차년도 성과관리로 넘긴다.

  지난해 실적·사진·지급 건·날짜는 올해 것이 아니다. 지난해 문장을 옮기지 않는다 — 결과보고서에 지난해 보고서와 같은 문장이 있으면 내보낼 때 「전년 문장」 경고가 뜨고 자동 다듬기가 고친다.
  정산자료·결과보고서·정산보고서 단계는 `prior/` 를 읽지 않는다(결과보고서는 메모에 옮겨진 것만 쓴다).
- **홈페이지(gepa.kr) 자료는 후보일 뿐이다.** 플랫폼이 사업명·세부사업 이름으로 찾아 `materials/web/` 에 받아 둔다. 사업명·행사 이름·일시가 맞는 글만 쓰고, 사진은 같은 행사의 올린 사진이 없을 때만 배치한다. 게시일은 행사일이 아니다 — 날짜는 본문의 일시로.

- **사업내용 쓰는 법**(담당자 2026-10-19: "3개 세부사업 그걸 누가 그렇게 글로 쓰냐", "123이면 123이고 ()면 ()고").

  한 줄에 번호(①②)와 괄호 머리말을 섞지 않는다. 둘 중 한 가지로 쓴다.

  ㅇ (사업내용)                             ㅇ (사업내용) 판로 확대·역량 강화·판매전으로 시장 활성화

  **계획서 사업내용이 분야 아래 세부사업으로 나뉘어 있으면 그 두 단계를 그대로 쓴다**(담당자 본보기 2026-10-21, 향토뿌리).
  `ㅇ` 줄에는 분야를 잇는 요약, `-` 줄은 `(분야)` 머리말 + 그 분야에서 한 일, `·` 줄은 `세부사업: 내용`. 계획서의 두 축(기업·유산)을 모두 담는다 — 한 축이 빠지면 누락이다.
  ````
  ㅇ (사업내용) 기업·유산 홍보 및 네트워킹, 향토뿌리기업 맞춤 역량강화 지원
  - (홍보·네트워킹) 향토뿌리기업 신규지정, 유산 및 기업 체험 프로그램 운영
  - (기업역량강화) 향토뿌리기업 대상 맞춤 지원사업 운영
  · 기술혁신: 컨설팅, 사업화(R&D) 지원
  · 디 자 인: 제품 포장재 디자인 및 제작 지원
  · 마 케 팅: 홍보물, IP 획득, 전시 박람회 참가 지원
  · 맞 춤 형: 기업 수요에 맞춘 제안 사업 지원
  ````
  (안 좋은 예: `- 홍보 및 네트워킹` 처럼 분야 이름만 있는 줄, 산업유산 이야기가 하나도 없는 사업내용)
  **같은 범주의 항목(나란한 `-` 줄)은 모두 한 줄로** 쓴다(담당자 2026-10-19: "뒷 문장을 줄여서 3줄을 다 똑같이 1줄로").
  한 줄은 머리말을 넣어 약 38자다 — 넘치면 "등을 통한", "지원을 통한 ○○ 강화" 같은 꼬리를 덜어 낸다. 한 줄만 두 줄로 넘어가면 보기 흉하다.
  나란한 괄호 머리말은 **글자 수가 같으면 띄어 쓰지 않는다** — `(서류심사)` `(현장실사)` `(심의의결)` 은 모두 네 글자라 그대로 쓴다(담당자 2026-10-21: "띄어쓰기는 뭐하러 해").
  띄어쓰기는 같은 묶음 안에 글자 수가 다른 머리말이 있을 때 짧은 쪽에만 넣는다. 맞출 상대가 없는 `-` 줄 머리말(`(사 업 포 기)` `(후 보 기 업)`, 줄 하나뿐인 `(계 획 변 경)`)은 띄우지 않는다 —
  "띄어쓰기를 왜 해야 하는지 생각하면 나올 수 없는 공백"(담당자 2026-10-21). 저장할 때 자동으로 붙여 쓰지만 처음부터 붙여 쓴다.
  띄어쓰기로 폭을 맞추는 것은 4글자 `(판 로 확 대)` 와 5글자 `(시장 활성화)` 처럼 **한 글자 차이일 때만**이다.
  띄어 써도 폭이 맞지 않거나 낱말이 쪼개져 어색하면 괄호 머리말을 쓰지 않는다. 머리말을 고를 때 글자 수가 같은 낱말을 먼저 찾는다.
- **진행 단계를 적는 `-` 줄은 괄호 대신 `이름: 내용`**(담당자 2026-10-21, 향토뿌리 신규지정 절을 직접 고침).
  서류심사, 현장실사, 위원회, 수여식처럼 일이 진행된 단계를 늘어놓는 하위 줄은 `- 서류심사: …` 로 쓴다. 폭 맞춤 띄어쓰기는 하지 않는다.
  이때 윗줄 `ㅇ (추진실적)` 에는 결과만 쓴다. 신청 수부터 심사까지의 과정은 아래 단계 줄이 보여 준다.
  ````
  ㅇ (추진실적) 향토뿌리기업 4개사 신규지정, 인증패 수여 및 현판 제작·설치
  - 서류심사: 업력·승계·고용인원 요건 미충족 3개사 제외, 7개사 현장실사 대상
  - 현장실사: 2025. 9. 19.~10. 1. 7개사 실사, 3개사 지정 포기
  - 육성위원회: 2025. 10. 31.(금) 4개사 심의, 참석 위원 6명 전원 찬성으로 지정
  - 수여식: 2025. 11. 26.(수) 경북도청 다목적홀, 신규지정 4개사 인증패 수여
  ````
  (안 좋은 예: `- (서 류 심 사)`, `- (현 장 실 사)`, `- (육성위원회)`, `- (수  여  식)` 는 폭이 서로 달라 줄 시작이 들쭉날쭉해 보였다)
  세부사업 번호(①②)는 Ⅱ 의 표와 절 제목에서만 쓴다. 요지 ◇ 둘째 줄도 "N개 세부사업을 추진하여"로 시작하지 않고 결과 수치로 바로 쓴다.
- `##` 절 안에서는 `□` 를 쓰지 않는다(절 칩 아래 □ 는 너무 무겁다) — `ㅇ (계    획)`, `ㅇ (추진실적)` 와 그 아래 `-`, `·`, 절 끝 `※ 목표 대비` 줄.
- 세부사업이 자료로 확인되지 않으면(예: 선정됐는데 지원금 지급 공문이 없음) 지어내지 말고 "미추진(사유 ○○)"으로 둔다.
- 기업별 지원금 표는 세부사업마다 본문에 `{{정산:기업별 세부사업="…"}}` 로 둔다(세부사업 이름은 원장의 세부사업과 똑같이). 금액·합계는 원장이 쓴다.
- **붙임은 쓰지 않는다**(```attach 블록 없음). 결과보고에 붙일 자료(선정 현황·지급 내역·명부·사진 등)는 이미 각각의 기안·지급 결재 때 들어간 문서라 다시 붙이지 않는다(담당자 2026-10-06). 대신 Ⅳ 의 마지막 문장 끝에 두 칸 띄우고 `끝.` 을 붙인다.
- **넣지 않는다**: 별도 결과요약 쪽, 추진절차 흐름도 그림(```flow), 심사기준·배점표, 추진체계, 계획서 일정표 복사, 강사 약력, 이자 든 정산표.
- **집행한 돈을 실적으로 잡지 않는다**(담당자 2026-10-07: "③ 기술혁신 실적 4개사 38,677 이게 뭐야?"). 실적은 무엇을 몇 개사·몇 명에게 했고
  어떤 결과가 났는지다. 기업별 지원 금액은 기업별 표(매크로)가 보여 주므로 (추진실적) 줄에는 "4개사 생산 자동화 설비 도입·시제품 개발 지원"처럼
  무엇을 몇 곳에 했는지만 쓴다. 천원 단위 금액은 (계    획)의 계획 예산에서만 쓴다. 세목별 예산 변경 금액은 결과보고서에 쓰지 않는다 — 정산보고서 변경내역이 보여 준다(규칙 14).
- **개조식으로 충분히 설명한다 — 화살표·축약·도식 금지**(담당자 2026-10-07: "화살표가 너무 많다. 설명이 충분히 담기면서도 한눈에 보기 좋게 개조식으로").
  화살표로 단계·변경·인과를 잇지 않는다. "7월에서 11월"을 화살표로 줄이지 말고 "당초 7월에서 11월로 변경" 처럼 쓴다(예산 변경 금액은 결과보고서에 쓰지 않는다, 규칙 14).
  한 항목은 **무엇을, 왜, 어떻게 해서, 어떤 결과**가 읽히는 1~2줄의 개조식 문장
  (명사형 종결 "…지원", "…선정", "…필요")으로 쓰고, 낱말만 늘어놓거나 기호(→, /, ⇒, ▶)로 줄이지 않는다. 표 칸 안에서도 같다.
  다 쓴 뒤 초안에서 화살표 기호를 찾아 하나도 남기지 않는다(내보낼 때 「편람·화살표」 경고로도 잡힌다).
- **(문제)·(개선) 같은 머리말을 줄마다 되풀이하지 않는다**(담당자 2026-10-07: "(문제) (문제) (문제) 너무 이상하다. 그냥 없이 써도 된다").
  총평·개선사항은 머리말 없이 "…하여 …했으므로, 차년도에는 …할 필요(계획)" 처럼 아쉬운 점과 대책을 한 문장으로 이어 쓴다.
  머리말은 (사 업 명)(사업기간)(계    획)(추진실적)처럼 항목마다 성격이 다른 줄을 구분할 때만 쓴다.
- **괄호 머리말을 단 줄에는 다른 괄호를 쓰지 않는다**(담당자 2026-10-19: "()로 키워드를 뽑을거면 그 문장에 또 다른 ()는 잘 사용 안함").
  `(선정방법) … 고득점 순 선정(동점 시 영업기간 우선)` 대신 `… 고득점 순 선정, 동점 시 영업기간이 긴 점포 우선` 처럼 쉼표로 잇는다.
  날짜의 요일 `2025. 10. 25.(토)` 만 예외다. 보충할 말이 길면 다음 줄 `※` 로 내린다.
- **되풀이되는 절차는 Ⅰ 에 한 번만**(담당자 2026-10-07). 접수, 선정, 협약, 과업 수행, 결과·청구서류 검토, 지원금 지급처럼
  모든 기업이 똑같이 거친 절차·선정방법·지급방법은 Ⅰ 의 (추진절차)(선정방법)(지급방법) 줄에 쓰고, Ⅱ 에서는 기업마다
  "과업 완료 후 서류 검토를 거쳐 지급" 같은 문장을 되풀이하지 않는다. Ⅱ 의 기업별 지원 현황은 **어느 기업에 어떤 내용으로 얼마**만
  (표 한 개). 경과(`-`)에는 절차와 다른 일 — 연장 공고, 요건 미비·포기, 계획 변경, 추가 선정 — 만 남긴다.
- **Ⅰ 의 계획 내용은 사업계획(안)의 문구로 쓴다 — 바꿔 말하지 않는다**(담당자 2026-10-21: "계획안에 그 공문서용 언어로 다 적혀있을텐데").
  (추진절차)(선정방법)(지원내용)(지원한도)처럼 계획서에 이미 있는 내용은 계획서의 낱말을 그대로 옮긴다. 줄여야 하면 단계를 빼되 남긴 단계의 낱말은 바꾸지 않는다.
  계획서의 단서(괄호·※ 줄)도 빠뜨리지 않는다 — 결과에 영향을 준 조건일 수 있다(아래 예의 "2개월 이내 미착수 시 선정 취소"는 마케팅 포기·차년도 반영과 이어진다).
  계획서 흐름도의 `»` 는 쉼표로 이어 한 줄로 쓴다(화살표를 쓰지 않는다).
  | 바꿔 쓴 것 (×) | 계획서 문구 (○) |
  |---|---|
  | (추진절차) 공고·접수, 선정·통보, 협약 체결, 기업 과업 수행·결과보고, 서류 검토 후 지원금 지급 | (추진절차) 공고 및 수요기업 모집, 기업선정 및 통보, 협약 체결, 기업별 과업 추진 및 결과 보고, 서류검토 후 지원금 지급 |
  | (선정방법) 역량 강화는 신청 접수순 선정, 신규지정은 서류심사·현장실사·육성위원회 심의로 지정 | (선정방법) 역량강화는 신청 접수순으로 선정, 선정 2개월 이내 미착수 시 선정 취소<br>※ 전년도 동일 항목 수혜기업 후순위 지원<br>신규지정은 요건심사 및 정량평가, 기업별 현장실사, 육성위원회를 통한 종합심사 |
  머리말 줄 안에는 다른 괄호를 쓰지 않으므로 계획서의 `(선정 2개월 이내 …)` 는 쉼표로 잇는다.
- **문서번호는 본문에 넣지 않는다**(담당자 2026-10-07: "반 페이지가 문서번호, 문서번호… 하나하나 번호 안 보여 줘도 된다").
  Ⅰ 의 `※ 근거:` 줄도 두지 않는다(담당자가 본보기에서 지움, 2026-10-21 — 결재권자는 사업계획·변경 승인 문서를 이미 안다). Ⅱ·Ⅳ 의 경과·변경·계획 대비 줄에도 `(ESG·기업지원팀-○○○, 2025. ○. ○.)` 를 달지 않는다.
  읽는 사람에게 필요한 것은 **무엇을 언제 해서 어떤 결과가 났는지**다 — 날짜는 공고·접수·선정·행사처럼 결과를 가르는 것만 쓴다.
- **경과는 단계마다 한 줄로 요약한다.** "(모집) 2025. 3. 10.~5. 2. 1·2차 모집 결과 4개사가 신청하여 2개사 선정(2개사 요건 미비)" 처럼 결과 수치가 보이게.
  기업별 접수일·요건 판정 같은 세부는 기업 표 한 개로 모으거나 뺀다. `-` 아래 `·` 로 기업마다 줄을 늘어놓지 않는다.
- **금액을 가운뎃점으로 늘어놓지 않는다**("5,000·7,500·10,000천원" ×). 지원 한도가 요건에 따라 다르면
  "기업당 최대 10,000천원(요건에 따라 차등)" 처럼 최대치와 차등만 쓴다(담당자 2026-10-07).
- **사진 대지**(```photos): 행사·현장실사·시설 개선처럼 사진이 결과를 보여 주는 세부사업 절 끝에 2~4장(2장씩 한 줄).
  `materials/index.md` 의 「사진」 목록에서 고르고, **넣기 전에 Read 로 열어 무엇을 찍었는지 확인**한 뒤 설명을 단다
  (설명은 "(체험) 고령메주 전통 장 만들기 체험" 처럼 무엇·어디 — 확인 못 한 내용은 쓰지 않는다). 문서 사진·현수막·카드뉴스·스캔본은 넣지 않는다.
  쓸 사진이 없으면 사진 대지를 만들지 않는다.
  ````
  ```photos
  materials/images/3062_…_Body_04.bmp | (체험) 농업회사법인㈜거인식품 돈육 가공 시설 견학
  materials/images/3062_…_Body_07.bmp | (체험) 고령메주 전통 장 만들기
  ```
  ````
  **사진은 한 기준으로 고른다**(담당자 2026-10-21, 향토뿌리 수여식).
  4개사가 대상인 행사면 4개사 모두의 개별 사진을 넣거나, 단체 사진 한 장만 넣는다. 두 곳만 개별 사진이고 나머지는 단체·장면 사진인 식으로 섞지 않는다.
  모든 대상의 사진이 없으면 단체 사진만 쓴다.
  **설명에는 칸마다 다른 것만 쓴다.** 행사 이름·날짜·장소가 모든 칸에 같으면 칸마다 되풀이하지 않는다.
  그런 정보는 바로 위 `- 수여식: 2025. 11. 26.(수) …` 줄이 이미 말한다. 칸에는 `㈜영도벨벳`, `민속주안동소주` 처럼 그 사진만의 것을 쓴다.
  ````
  ```photos
  materials/web/photo_688_02.jpg | ㈜영도벨벳
  materials/web/photo_688_03.jpg | 민속주안동소주
  materials/web/photo_688_04.jpg | 풍기인삼공사영농조합법인
  materials/web/photo_688_05.jpg | ㈜삼진
  ```
  ````
  (안 좋은 예: 네 칸 모두 `(수여식) 2025. 11. 26. …` 로 시작, 단체 사진·누군지 모를 수여 장면·기업 2곳 개별 사진이 섞임)
  칸마다 날짜나 활동이 다르면 그것이 "다른 것"이라 칸마다 쓴다. 담당자가 잘 썼다고 한 예(2026-10-21, 향토뿌리 체험 프로그램):
  ````
  ```photos
  …_Body_05.png | (견학) 2025. 11. 4. 고령메주 장류 발효 시설
  …_Body_08.png | (체험) 2025. 11. 4. 고령메주 전통 된장 만들기
  …_Body_10.png | (탐방) 2025. 11. 4. 산업유산 호텔금오산 555호 객실
  …_Body_16.png | (탐방) 2025. 11. 5. 산업유산 오운여상
  ```
  ````
  견학·체험·탐방으로 활동이 다르고 날짜도 이틀에 걸쳐 있어, 머리말과 날짜가 사진을 구분해 준다.

### 2-1. 문장 쓰는 법 — 잘 쓴 결과보고서는 이렇게 쓴다

진흥원 결과보고서 36건을 정독해 잘 쓴 문서의 공통 요령을 뽑았다(예문·약점 사례는 `reference/result-writing.md`). 쓰기 전에 그 파일의 §1(자리별 요령)을 읽는다.

1. **요지 둘째 줄은 결과 수치로(계획서 ◇ 가 목적 하나일 때 — 두 축이면 표의 ◇ 요지 칸대로).** 산출(몇 개사·몇 명)을 먼저, 이어서 성과 수치 하나(취업자, 입점·계약, 인증 취득, 상담액 등)를 붙인다. 성과 수치가 없으면 "○개사 신청, ○개사 선정(○:1)"처럼 경쟁률을 쓴다. 배경 설명으로 요지를 채우지 않는다.
2. **(추진실적) 한 줄은 신청, 선정, 지원 완료 순**으로 쓰고 빠진 수는 쉼표 뒤에 사유와 함께 둔다 — "37개사 신청, 27개사 선정, 26개사 지원 완료, 1개사 사업 포기".
3. **목표 대비는 절 끝 `※` 한 줄에 목표값과 실적을 한 쌍으로 쓴다**(담당자 2026-10-19 — `- (계획 대비) 계획한 6개 점포 모두 지원` 같은 말투는 쓰지 않는다). 계획대로: "※ 목표 9개사, 9개사 지원으로 100% 달성". 초과: 초과분이 어디서 났는지 — "※ 목표 10개사, 잔액 활용으로 12개사 지원". 미달·변경: 원인(기업 사정, 요건 미달, 설계 변경, 외부 요인 가운데 하나) — "※ 목표 4개사, 평가 50점 미만 1개사 미선정으로 3개사 지정". 남은 예산의 처리는 Ⅲ 의 ※ 줄에 둔다.
4. **대조 기준값은 계획서에서 이 순서로 찾는다: 명시된 성과목표, 사업규모·모집규모(○개사 정도), 세부사업별 계획 수.** 진흥원 계획서의 95%는 성과지표가 없으므로 대개 사업규모가 기준이다. 계획서에 없던 지표를 결과에 쓰면 "참고 지표(계획 목표 아님)"로 구분한다. 계획서 목표를 확인하지 못하면 '사업목표' 줄을 만들지 않는다. 계획서에 성과지표가 있으면 Ⅳ 주요 성과 위에 `지표명│목표│실적│달성률` 표를 둔다.
5. **주요 성과 ㅇ 하나는 "[산출]하여 [확인된 결과]" 한 문장.** 확인된 결과는 완료된 사건(입점·계약·인증 취득·취업·투자 검토 등록 등)이나 측정 수치(전년 대비 증감, 조사 결과)만 쓴다 — "구직자 484명에게 면접비를 지원하여 216명 취업 성공". 확인된 결과가 없으면 산출과 그 구성(어느 분야에 몇 건이 몰렸는지)까지만 쓰고 "기여·도모·활성화"로 효과를 단정하지 않는다.
6. **"예상·기대·가능성"은 성과 자리에 쓰지 않는다.** 전망은 총평에 한 항목 이하로, "판매 실적은 차년도 사후 조사로 확인할 계획"처럼 확인 방법과 함께 쓴다.
7. **형용사·부사(실질적, 효과적, 성공적, 극대화, 큰 관심, 다수, 많이)를 쓰려면 같은 문장에 수치를 둔다.** 셀 수 있는 것은 센다 — "다수의 문의" 대신 "공고 7일 만에 접수 마감".
8. **의도형 종결("~하고자 했음", "~도모하고자 함")을 쓰지 않는다.** 한 일은 "~운영", "~지원", "~확인"으로, 할 일은 "~할 계획", "~필요"로 끝낸다. "~도모"는 Ⅰ·요지의 목적 줄에만.
9. **계획서의 목적 문장이나 다른 사업·전년 보고서의 총평 문장을 Ⅳ 에 옮기지 않는다.** Ⅳ 의 모든 ㅇ 에는 이 사업의 수치나 사실이 하나 이상 들어간다.
10. **총평 개선 항목은 "[현상과 수치]로 [영향]이 있었으므로, 차년도에는 [실행 단위의 대책]" 한 문장.** 대책은 선정방식, 추진기한, 매뉴 구성, 사전 안내, 모집 시기처럼 바로 바꿀 수 있는 것. "지속적 지원 필요", "예산 확대 필요"를 원인 없이 쓰지 않는다.
11. **집행잔액이 사업비의 5% 이상이면(summary.md 의 집행률 95% 미만) 총평에 원인과 대책을 한 항목으로 쓴다.** 잔액이 큰 사업을 "예산 확대 필요"로 맺지 않는다. 확대가 필요하면 "신청 225개사 중 91개사만 선정"처럼 수요 근거를 같은 문장에 둔다.
12. **만족도는 조사했을 때만, 개요 한 줄 "대상 ○명 중 ○명 응답(응답률 ○%), 방법, 척도"와 함께.** 결과는 전체 평균과 가장 낮은 항목을 쓰고, 가장 낮은 항목을 총평 개선사항으로 잇는다. 응답률 50% 미만이면 "응답자 기준"이라 한정한다.
13. **전년 대비 증감은 증가율((올해-작년)/작년)로 쓴다** — 비율(올해/작년)을 증가율처럼 쓰지 않는다. 전년 수치는 자료에 있을 때만 쓴다.
14. **경위 대신 결과 하나, 예산 변경 세부는 정산보고서로**(담당자 2026-10-21). `- (계획 대비) 당초 계획(1~2개사) 대비 규모 확대, 우수 기업 4개사 지정` 처럼 그 자리의 요점 하나만 쓴다. 심사 절차·사정·승인 경위를 연결어미로 잇지 않고, 세목별 변경 금액("4,500천원에서 6,480천원으로 증액")은 결과보고서에 쓰지 않는다. 고치기 전후 예는 `reference/result-writing.md` §1-3-2.

### 2-2. 표로 보여 줄 것 — 줄글로 늘어놓지 않는다

담당자가 본보기로 든 도 위원회 안건 문서(2026-10-21, "표 등이 많아서 좋을 것 같다")는 비교·구성·변경을 줄글 대신 표로 보여 준다.
결과보고서도 **둘 이상을 견주는 내용은 표로** 쓴다. 표 위에는 `(단위: …)`, 아래에는 `※` 주석 한두 줄(계획 대비 실적 표는 ※ 없이).
`ㅇ` 아래 `-` 가 하나뿐이면(편람: 항목이 하나면 기호 없음) 윗줄에 쉼표로 잇거나, 정산보고서가 보여 줄 행정 세부(항목 간 금액 조정 등)면 지운다.

| 자리 | 표 | 모양 |
|---|---|---|
| Ⅱ 첫 □ | 세부사업별 계획 대비 실적 | `분야│세부사업│계 획│실 적` 4열 — 비고 열·표 아래 ※ 줄 없음(위 표 Ⅱ 칸) |
| Ⅳ □ 주요 성과 위 | 성과지표·전년 대비 (자료가 있을 때만) | 두 줄 머리 `header-rows=2`: `구 분│목 표│실 적│달성률` 또는 `구 분│'24년│'25년│증 감` |
| Ⅳ □ 우수사례 | 사례 한 건에 표 한 개 | `구 분│내 용` 2열 — 행: 대 상(지역, 업종, 업력) / 사업목표 / 지원내용 / 지원 전 / 지원 후 / 성 과 (안건 문서의 「항목│내용」 수정사항 표 모양, 본보기 `reference/result-writing.md` §1-8) |
| Ⅳ □ 총평 및 차년도 반영사항 | 차년도 반영 | `구 분│'25년 결과│차년도 반영(안)` — 행: 예산 배분·선정 방식·모집 시기·사업내용·성과관리 중 메모 §5 에 있는 것만 |
| 계획 변경이 있었던 절 | 변경 전후 | 두 줄 머리 `항 목│당 초│변 경│사 유` — 예산 변경은 `{{정산:변경내역}}` |

- 칸 글은 짧게(명사구), 칸 안 줄바꿈은 `<br>`. 화살표로 전후를 잇지 않는다 — 전후는 열을 나눈다.
- 같은 내용을 표와 ㅇ 줄에 두 번 쓰지 않는다. 표가 보여 주면 ㅇ 줄은 해석 한 줄(무엇이 가장 컸고 왜)만.
- 표가 없는 절이 쪽 하나를 줄글로 채우면 표로 바꿀 수 있는지 먼저 본다.
- 우수사례 □ 아래 요약은 한 줄뿐이므로 `ㅇ` 를 붙이지 않는다(편람: 항목이 하나면 기호 없음). 사례가 둘이면 `ㅇ (사례 1) …`·`ㅇ (사례 2) …` 아래에 표를 하나씩.
- 문서가 표로 끝나지 않게 한다 — 차년도 반영 표 다음에 총평 ㅇ 한 줄을 두고 그 끝에 `  끝.` 을 붙인다(표 행 끝에 붙이면 표가 깨진다).
