# GEPA 모집 공고문 작성 규격

참고 원문 분석: `reference/design-system.md` (§8 골격 템플릿 포함).

## 자동 생성되는 부분 (front-matter로만 제어)
표지(공고번호·제목·인사말·연월·기관장), 1쪽 안내박스(접수방법·문의·선정결과 통보), 로고, `1. 모집개요` 표, `2. 지원절차` 절차도와
`※ 상기 일정은…` 문구는 front-matter에서 자동 생성된다. 본문에는 쓰지 않는다.

```yaml
---
family: notice
공고번호: 2026070000          # 공고 제N호의 N
사업명: 2026년 안동시 수출기업 역량강화 지원사업
모집대상: 참여기업
부제: 수출매뉴얼 지원          # 선택
주관기관: 안동시              # "OO와/과 (재)경상북도경제진흥원에서 추진하는"
지역: 안동시
대상기업군: 수출유망 중소기업      # 인사말 "{지역} 내 {대상기업군}의 많은 참여를" — "도내/관내"를 넣지 않는다(지역이 앞에 붙음)
공고연월: 2026. 07.
접수: { 이메일: gepa_north@naver.com, 우편주소: 경상북도 안동시 북순환로 387, 2층 경상북도경제진흥원, 부서명: 북부지소, 전화: 054-900-3801, 선정결과통보: 기업별 개별통보(필요시 접수 홈페이지 공고) }

  - { 라벨: 사업명, 값: … }

  - { 라벨: 신청방식, 값: "이메일 접수: …\n우편(등기): …" }

  - { 라벨: 신청서접수일자, 값: 2026. 07. 01.(수) }

  - { 단계: 모집공고, 일정: ’26. 07. 01. }
  - { 단계: 신청·접수, 일정: ’26. 07. 01. ~ 07. 15. }
```

## 시군·기관 공모일 때
신청 주체가 기업이 아니라 시군·기관이면(예: 시군 공모로 운영기관을 뽑는 사업) 고정문구 다섯 개에 `대상=기관` 을 붙인다:
`{{boilerplate:참여제한대상 대상=기관}}`, `{{boilerplate:예산상황 대상=기관}}`, `{{boilerplate:기업부담금 대상=기관}}`,
`{{boilerplate:지급방법 대상=기관}}`, `{{boilerplate:기타유의사항 대상=기관 주관기관=…}}`. 기업 표현(기업계좌 송금, 휴업 중인 기업,
기업부담금)이 사실과 달라지기 때문이다. `모집대상`은 "참여 시군"·"운영기관" 등으로, `대상기업군`은 "22개 시군"처럼 쓴다.
조사·계획 단계의 내부 산식 주석(`(산출)`, `평균 18.75명`)은 대외 공고문에 옮기지 않는다.

## 문체
- 개조식, 존칭 없음. 공고 제목: `「사업명」 참여기업 모집 공고(부제)`.
- 고정 문구는 반드시 매크로. 임의 문장으로 대체하면 검토에서 오류 처리된다.
- 굵게: 괄호 라벨 `**(지원대상)**`, 소제목 `**신청·접수**`.
- 색상 강조는 `{red}…{/red}`만 드물게(동점 처리 기준 등).
- 날짜는 모두 확정값으로 요일까지 쓴다: `2026. 7. 15.(수) 18:00`. 참조 공고안에 있던 `07. 00.` 같은 00 자리표시자는 완성 문서에서 금지(검토에서 error). 근거가 없으면 합리적 일정을 넣고 `※ 일정은 주관기관 협의 후 확정` 주석을 단다.
- 공고번호는 `2026MMNNNN` 꼴로 월까지 채운다(예: 2026070001).
