# GEPA 보도자료 DESIGN SYSTEM — 2026년 서식 (2026-02-26 참고본 실측)

Source: `보도자료_경상북도경제진흥원 CES 2026 리뷰 & 인사이트 콘서트 in 경북 개최.pdf` (전략기획팀, 2026-02-26 배포, 3쪽).
이전 서식(2023-02-17 강소기업육성실 보도자료, 함초롬바탕 본문 + 파란 괘선 제목 상자 + 회색 항목 상자)은
`templates/press/_prev/` 에 남겨 두었다. 템플릿 패키지(`templates/press/pkg/`)는 2023 참고본의 header.xml(글꼴 표에
HY견고딕·함초롬돋움 추가)과 쪽 설정을 그대로 쓰고, `BinData/image1.png` 만 CI 매뉴얼 기본로고에서 뽑은 GEPA 마크로
바꿨다. `Contents/section0.xml` 은 `lib/hwpx/writers/press.ts` 가 전부 새로 쓴다.

Units: 1 pt = 100 HWPUNIT, 1 mm = 283.465 HWPUNIT. 참고본 PDF 는 A4(596 × 840 pt), 본문 폭 44.6 ~ 531 pt(≈ 171 mm).

## 1. PAGE SETUP
2023 패키지의 secPr 을 그대로 쓴다 — A4 세로, 좌우 20 mm(본문 48190 HWPUNIT = 170 mm), 상하 10 mm, 머리말·꼬리말 10 mm.

## 3. ELEMENT-BY-ELEMENT (document order)

### 3.1 머리표 (4 × 4 표, 폭 47900, 높이 8000 = 4행 × 2000)
```
col: 24270 (로고·로고타입 블록) | 1070 (빈 칸, 선 없음) | 7170 (라벨) | 15390 (값)
┌──────────────────────┐   ┌──────────┬────────────────┐
│       GEPA 마크       │   │ 제공일자  │ 2026. 2. 26.   │  row 0   ─ 바깥 0.4 mm
│      (rowspan 2)      │   ├──────────┼────────────────┤          ─ 안쪽 가로선 0.12 mm
│                      │   │ 제공부서  │ 전략기획팀      │  row 1
├──────────────────────┤   ├──────────┼────────────────┤  ─ 블록 사이 0.4 mm
│ 보도자료【26. 2. 26.】 │   │ 주책임자  │ 장은영 팀장     │  row 2
│      (rowspan 2)      │   ├──────────┼────────────────┤
│                      │   │ 담 당 자  │ 권하경 과장     │  row 3
└──────────────────────┘   └──────────┴────────────────┘
```
- 왼쪽 블록 두 칸과 오른쪽 블록의 바깥 테두리는 0.4 mm, 오른쪽 블록 안의 가로선과 라벨/값 사이 세로선은 0.12 mm.
- 가운데 빈 칸은 네 변 모두 선 없음(두 블록이 떨어져 보인다).
- 로고 칸: 그림 가운데 정렬. 로고타입 칸: "보도자료"(HY헤드라인M 35) + `【26. 2. 26.】`(휴먼모음T 15) 한 문단, 왼쪽 맞춤, 세로 가운데.
- 라벨·값: 맑은 고딕 12pt 가운데 정렬, 160 %. 값은 front-matter 에서 — 제공일자 ← `배포일`(연도 네 자리·요일 제거·마침표로 끝),
  제공부서 ← `담당부서`, 주책임자 ← `책임자`, 담 당 자 ← `담당자`. 사람은 **이름 직위** 순서("장은영 팀장"; "실장 남상범" 은 뒤집는다).

### 3.2 연락처 줄 (1 × 1 표, 폭 47900, 높이 2030)
`전화: 054.470.8527 / FAX: 054.472.2989 / 전자우편: nancy.kwon@gepa.kr` — HY견고딕 13pt 가운데. 칸의 아래 변만 0.4 mm 검정 괘선.
전화·FAX 는 붙임표를 마침표로 바꾼다(`연락처`·`팩스`); 팩스가 없으면 기관 대표 FAX 054.472.2989.

### 3.3 제목 상자 (1 × 1 표, 폭 47900) + 부제
- 제목: HY헤드라인M 20pt 검정, 가운데, 165 %, **두 줄까지 그대로**(자간·장평 축소 없음). 한 줄 약 24자, 48자 초과 시 경고.
- 칸의 아래 변만 0.4 mm 회색(#A6A6A6) 괘선 — 제목과 부제 사이의 가는 선.
- 부제: 맑은 고딕 12pt 회색(#808080) 가운데, 160 %, 위 5 pt. 앞뒤 `- -` 는 쓰지 않는다.

### 3.4 본문 (맑은 고딕 13pt, 양쪽 정렬, 185 %)
| DSL | 출력 |
|---|---|
| `□ …` (body1) | `□ ` + 글. 내어쓰기 1950(둘째 줄이 □ 뒤에 맞춤). 첫 □(리드)은 위 18 pt, 그 뒤의 □(인용문 등)은 위 10 pt |
| `# 소제목` (sectionBar) | `■  소제목` — 본문과 같은 13pt(굵게 아님), 위 10 pt · 아래 5 pt, 내어쓰기 2600, 다음 문단과 묶음 |
| 기호 없는 줄 (pressBody) | 첫 줄 앞에 반각 공백 한 칸, 둘째 줄부터 6.3 pt 내어쓰기. 문단 사이 여백 0 |
| `ㅇ` / `-` / `·` (body2~4) | `  • ` / `    - ` / `      · ` 항목, 내어쓰기 2600 / 3900 / 5200. 회색 상자는 쓰지 않는다 |
| 빈 줄 (blank) | **무시** — 새 서식은 문단 사이 빈 줄이 없다. 간격은 위 표의 문단 여백으로 낸다 |
| `※` / `*` (note) | 맑은 고딕 12pt ※ 줄 |
| `붙임` (attachmentList) | `붙임  … 끝.` 13pt, 위 10 pt |
| image / table / procedureFlow | 다른 가족과 같은 공용 emitter (표: 맑은 고딕 11pt, 머리글 #F2F2F2) |

### 3.5 끝
인용문 `□` 문단으로 끝난다. 사진이 있으면 그 아래 inline image(참고본은 행사 포스터 전면).
