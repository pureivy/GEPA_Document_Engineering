# GEPA 보도자료 작성 규격 (2026년 서식)

```yaml
---
family: press
기관: (재)경상북도경제진흥원
배포일: 2026. 7. 1.             # 머리표 "제공일자"(연도 네 자리) 와 로고타입 옆 【26. 7. 1.】 둘 다 여기서 만든다 — 요일은 적지 않는다
보도시점: 즉시                  # 또는 "2026. 7. 2.(목) 조간"
담당부서: 북부지소              # 머리표 "제공부서"
책임자: 이유선 실장             # 머리표 "주책임자" — **이름 직위** 순서
담당자: 김OO 팀장               # 머리표 "담 당 자" — 이름 직위 순서
연락처: 054-900-3801            # "전화: 054.900.3801" 로 출력
팩스: 054-472-2989              # "FAX: …" (없으면 기관 대표 FAX)
이메일: gepa_north@naver.com    # "전자우편: …"
제목: 경북경제진흥원, 안동시 수출기업 역량강화 지원사업 참여기업 모집
부제: 7월 15일까지 접수… 기업당 최대 300만원 수출매뉴얼 지원
사진: false
붙임: [사업 공고문 1부]
---
```

## 본문 구조 (반드시 이 순서)

```
□ (재)경상북도경제진흥원(원장 박성수)은 안동시와 함께 … 를 7월 1일부터 15일까지 모집한다고 밝혔다.

# 소제목 1 (예: 사업 개요 — 무엇을, 누구에게, 얼마나)
지원 대상은 …
지원 내용은 …

# 소제목 2 (예: 신청 방법)
신청은 … 까지 … 로 접수하며, 문의는 … 로 하면 된다.

□ 박성수 원장은 "…"라며 "…"고 말했다.
```

1. **리드**(첫 줄, `□ `로 시작): 누가·무엇을·언제·어디서·왜. 한 문단.
2. **`#` 소제목 2~3개**: 각 소제목 아래 일반 문단 1~3개(기호 없이 바로 글). 소제목은 신문 중간제목처럼 내용을 요약하는 한 구절(`'AI는 이제 행동한다'` 식 인용 가능). 출력은 `■  소제목` 줄이 된다.
3. **인용문**(마지막 줄, `□ `로 시작): "박성수 원장은 “…”라고 말했다."
4. 항목 나열이 꼭 필요하면 `ㅇ` 줄(출력 `• `)을 쓴다 — 회색 상자는 더 이상 없다. 한 항목은 한두 줄.
5. **문단 사이에 빈 줄을 넣어도 출력에는 간격이 생기지 않는다**(새 서식은 문단 사이 빈 줄 없음). 소제목 위·아래 간격은 자동.

출력 디자인(`reference/design-system.md`, 2026-02-26 보도자료 기준): 머리표 표(GEPA 마크 · 보도자료【배포일】 ‖ 제공일자/제공부서/주책임자/담당자) → 전화·FAX·전자우편 줄 → 제목(HY헤드라인M 20pt, **두 줄까지**) → 회색 괘선 → 부제(맑은 고딕 12pt 회색) → 맑은 고딕 13pt 185 % 본문. **글자 수(공백 포함)**: 제목 한 줄 24자 내외, 48자 초과 금지. 부제 40자 이하 한 줄. 부제 앞뒤 `- -` 는 쓰지 않는다.

부서 정식 명칭 → 책임자 (2026년 9월 기준):

| 부서(정식 명칭) | 소속 팀·지소 | 책임자 |
|---|---|---|
| 경영기획실 | 경영지원팀, 전략기획팀 | 남상범 실장 |
| 강소기업지원실 (강소기업육성본부 산하) | ESG·기업지원팀, 마케팅팀 | 이명하 실장 |
| 일자리민생경제지원실 (강소기업육성본부 산하) | 일자리종합지원팀, 민생경제지원팀 | 이유선 실장 |
| 지역산업지원단 (강소기업육성본부 산하) | 동부지소, 북부지소 | 남상조 단장 |
| 강소기업육성본부 | — | 송호준 본부장 |

프로젝트 부서명이 팀·지소 이름이면 그 팀이 속한 실·단의 정식 명칭을 `담당부서`에 쓰고, 그 실·단의 책임자를 `책임자`에 **이름 직위** 순서로 쓴다.

규칙: 원장 성명은 **박성수**(2026년 9월 기준, 자리표시자 금지). 담당부서는 위 표의 정식 명칭으로 쓴다(약칭 "일자리민생" 금지). 문어체 "~다" 종결, 1,200~1,800자, 약어 첫 등장 시 풀어쓰기, 날짜는 `7월 1일(수)` 형식, 공고문에 없는 숫자 금지.
