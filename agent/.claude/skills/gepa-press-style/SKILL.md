# GEPA 보도자료 작성 규격

```yaml
---
family: press
기관: (재)경상북도경제진흥원
배포일: 2026. 7. 1.(수)
보도시점: 즉시                 # 또는 "2026. 7. 2.(목) 조간"
담당부서: 북부지소
책임자: 실장 이유선          # 머리표 "작성자" 첫 줄(직위 이름) — 아래 부서 표에서 채운다
담당자: 김OO 팀장
연락처: 054-900-3801
이메일: gepa_north@naver.com
제목: 경북경제진흥원, 안동시 수출기업 역량강화 지원사업 참여기업 모집
부제: 7월 15일까지 접수… 기업당 최대 300만원 수출매뉴얼 지원
사진: false
붙임: [사업 공고문 1부]
---
```

본문(모두 일반 문단, 문단 사이 빈 줄):
1. **리드**(1문단): 누가·무엇을·언제·어디서·왜. "(재)경상북도경제진흥원(원장 박성수)은 안동시와 함께 … 를 7월 1일부터 15일까지 모집한다고 밝혔다."
2. **사업 개요**(1~2문단): 목적, 지원대상, 지원내용·한도, 규모(숫자는 공고문과 동일)
3. **신청 방법**(1문단): 기간, 방법, 문의처
4. **인용문**(1문단): "박성수 원장은 “…”라고 말했다."
5. 필요 시 `□ 지원내용` + `ㅇ` 항목으로 핵심을 정리한 개조식 블록 1개 — HWPX에서는 연속된 항목이 **회색 상자**(함초롬바탕 14pt)로 출력된다: `□` 줄은 굵은 소제목, `ㅇ` 줄은 `•` 항목, `-` 줄은 들여쓴 세부 항목. 소제목 문구는 항목의 괄호 라벨과 겹치지 않게 쓴다(예: 소제목 "사업 개요", 항목 "(지원내용) …"). 한 항목은 한두 줄로 짧게 쓴다.

출력 디자인(`reference/design-system.md`, 2023.02.17 보도자료 기준): 머리표 표(GEPA 로고·보도자료 로고타입·【배포일】·담당부서/작성자/연락처) → 파란 괘선 제목 상자(제목 함초롬바탕 18pt B, `- 부제 -`) → 함초롬바탕 15pt 180% 본문(문단 사이 빈 줄). **글자 수 규칙(공백 포함, 한 줄 출력 기준)**: 제목 18pt — **26자 이하 권장, 36자 초과 금지**. 부제 16pt — **30자 이하 권장, 42자 초과 금지**. 권장치를 넘으면 자간·장평이 자동으로 줄어들고(장평 90%·자간 −20% 한계), 최대치를 넘으면 두 줄로 밀려 검토에서 반려된다. 부제 앞뒤의 `- -`는 자동으로 붙으므로 쓰지 않는다.

부서 정식 명칭 → 책임자 (2026년 9월 기준):

| 부서 | 책임자 |
|---|---|
| 일자리민생경제지원실 | 실장 이유선 |
| 강소기업지원실 | 실장 이명하 |
| 경영전략실 | 실장 남상범 |
| 지역산업지원단 | 단장 남상조 |
| 강소기업육성본부 | 본부장 송호준 |

규칙: 원장 성명은 **박성수**(2026년 9월 기준, 자리표시자 금지). 담당부서는 위 표의 정식 명칭으로 쓴다(약칭 "일자리민생" 금지). 문어체 "~다" 종결, 1,200~1,800자, 약어 첫 등장 시 풀어쓰기, 날짜는 `7월 1일(수)` 형식, 공고문에 없는 숫자 금지.
