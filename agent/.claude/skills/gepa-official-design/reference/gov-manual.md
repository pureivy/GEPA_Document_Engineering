## 3. 항목의 구분 (규칙 제2조제1항, 편람 제2장 4-다)
1. 항목 기호 순서: **1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮**. 필요하면 **□, ○, -, ·** 같은 특수 기호를 쓸 수 있다(전자화 오류가 잦은 특수기호는 금지).
2. 표시 위치: **첫째 항목 기호는 왼쪽 기본선**에서 시작하고, **둘째 항목부터는 바로 위 항목 위치에서 오른쪽으로 2타씩** 옮겨 시작한다(2타 = 한글 1자 = 스페이스 2번).
3. 항목 기호와 내용 사이는 **1타**.
4. 두 줄 이상이면 둘째 줄부터 **항목 내용의 첫 글자에 맞춰** 정렬(내어쓰기)이 원칙(왼쪽 기본선 정렬도 허용, 문서 안에서는 한 가지로).
5. **항목이 하나뿐이면 기호를 붙이지 않는다.**
6. 하위 항목은 위계대로 배열한다(서식 설계기준은 3단계 초과 금지 — 서식에 한함).
7. 가독성을 위해 항목 사이 위아래 여백은 자유롭게 둔다.

```
□ 첫째 항목                 ← 왼쪽 기본선(0타)
  ○ 둘째 항목               ← 2타
    - 셋째 항목             ← 4타
      · 넷째 항목           ← 6타
    ※ 둘째 항목에 딸린 참고  ← 딸린 항목의 내용 첫 글자 위치
```
→ 우리 구현: `PlanMeta.ladder: "gov"`(기본) = □0 / ㅇ2 / -4 / ·6 / ※·* 는 바로 위 항목보다 2타 안쪽. `"gepa"` = 참고 문서 관행(□1 / ㅇ2 / -3 / ·4). 둘째 줄부터는 접두어 폭만큼 내어쓰기(공통).

## 4. 붙임과 "끝" 표시 (규칙 제4조제4·5항)
- 첨부물이 있으면 본문이 끝난 줄 다음에 `붙임` 표시 + 명칭·수량. 둘 이상이면 항목으로 구분.
  - `붙임∨∨○○○계획서 1부.∨∨끝.`
  - `붙임∨∨1.∨○○○계획서 1부.` / `2.∨○○○서류 1부.∨∨끝.`
- **끝 표시**: 본문 마지막 글자에서 **한 글자(2타) 띄우고 `끝.`**. 첨부물이 있으면 붙임 표시문 다음에. 오른쪽 한계선에서 끝났으면 다음 줄 왼쪽 기본선에서 2타 띄우고.
- **본문이 표로 끝나면**: 표의 마지막 칸까지 채워졌으면 표 아래 왼쪽 기본선에서 2타 띄우고 `끝.`; 표 중간에서 끝나면 `끝.` 대신 다음 칸에 `이하 빈칸`.
- 붙임은 본문 바로 다음 줄이든 한 줄 띄우든 무방.
