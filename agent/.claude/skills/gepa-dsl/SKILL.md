# GEPA DSL

정본 문법: `reference/grammar.md` (예제 포함). 핵심 요약:

- 문서 = YAML front-matter(`---` … `---`, `family:` 필수) + 본문. YAML 값에 쉼표·콜론·`#`이 있으면 "따옴표"로 감싼다(특히 `{ 라벨: …, 값: … }` 한 줄 표기).
- `# 제목` → 장(계획서: Ⅰ Ⅱ … 밴드 / 공고문: `N. 제목` 섹션바, 번호 자동) · `## 제목` → 절 칩(계획서)
- 줄 첫 글자로 역할 결정: `□` `ㅇ` `-` `·` `※` `*` (앞 공백은 쓰지 않는다)
- 글자 없는 줄 = 일반 문단(보도자료 본문), 빈 줄 = 문단 간격
- 인라인: `**굵게**`, `{red}…{/red}`, `{blue}…{/blue}`, `[텍스트](URL)`, 줄 끝 `\` = 같은 문단 줄바꿈
- `<pagebreak>` 쪽 나눔 · `(단위: 천원)` 단독 줄 = 표 캡션
- 표: GFM 파이프 표. 바로 윗줄에 `{table role=… widths=…}` 속성. `^` 위와 병합, `<` 왼쪽과 병합, 셀 안 `<br>`
- 펜스: ```` ```box ```` 목적 박스, ```` ```flow ```` 절차(`단계 | 시기` 한 줄씩), ```` ```image logo ````, ```` ```attach ```` 붙임 목록
- 매크로 `{{boilerplate:이름 키=값}}`: 고정 문구는 이 방식으로만
- 최종 답변은 `<<<DOC` 와 `DOC>>>` 사이에 DSL 전체를 넣고, 같은 내용을 지정된 파일(`<stage>/draft.dsl.md`)에 Write로 저장한다.
