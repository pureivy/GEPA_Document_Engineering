# 범정부오피스(범피스) 문서 양식 검토

검토일 2026-09-15 · 근거: 행정안전부 「범정부오피스 1100일차 매뉴얼」(2025. 11, 91쪽, `bumpis-1100-manual.pdf`),
소통혁신24 배포 페이지(KISA 범피스 1310, 2026. 7. 7. 취약점 0), 서울신문 2025-11-07 인터뷰, 나무위키 항목.

## 1. 범피스란

- 행정안전부 행정제도과 이경수 주무관(간호직)이 개발해 2023. 3.부터 무상 배포하는 **한컴오피스 한글용 문서 편집 자동화 프로그램**(Windows `.exe`, 한글 창을 붙잡아 매크로처럼 동작). 온나라 커뮤니티/혁신24/소통혁신24에서 배포, 중앙부처·지자체·공공기관 20여 곳 도입, 기관별 맞춤 버전(서울교통공사, 경상남도, 인천국제공항 등) 32종 개발 중.
- **문서 파일 형식이 아니다.** hwp/hwpx 어느 쪽이든 한글에서 열린 문서에 "행안부 보고서 서식"을 클릭 한 번으로 입히는 도구다. 따라서 우리 HWPX 생성기와의 관계는 "범피스가 만들어 주는 서식 규칙을 우리가 처음부터 지켜서 생성하면, 범피스 사용자가 추가 정리 없이 그대로 쓸 수 있고, 범피스로 후처리해도 깨지지 않는다"이다.
- 입력 문법(G서식변신): `제목:`, `배경:`, `소제목:`, `네모:`, `원:`, `바:`, `당구장:`, `별:`, `시간계획표:14:00:14:05:5':내용:담당` 같은 접두어 텍스트를 서식으로 변환. 우리 DSL(□ ㅇ - ※ * 글머리 + `#`/`##`)과 개념이 같다.

|---|---|---|

| ※ 참고 | **맑은 고딕 12pt**, 내어쓰기 | 8p |

## 4. 반영 사항 (이 프로젝트)

1. **사업계획서 `house` 프로필** — `PlanMeta.house: "gepa"(기본) | "bumpis"`. `bumpis`이면: □ HY헤드라인M 16pt(굵게 아님), 2단계 글머리 `○` 출력, ※/* 맑은 고딕 12pt, 아래 여백 10mm, 표 머리글 연파랑 + 0.5mm 상·하 굵은 선, `##` 절 제목 = 남색 번호 칩 + 파란 밑줄, 목적 박스 = 남색 이중선 글상자, 표지 = 연보라 제목 상자(결재란은 `결재` 메타가 있을 때만).
2. **공통 형식 유틸** `lib/docmodel/format.ts` — `koreanAmount(12340) → "금12,340원(금일만이천삼백사십원)"`, `govDate("2026-01-01") → "2026. 1. 1.(목)"`, `thousands()`, `deltaText()`(증감 표기). 스킬 문서에서 참조하고 검토(reviewer) 항목에 날짜·금액 형식 검사를 추가.
3. **스킬 갱신** — `gepa-plan-design`에 "범정부 공통 기준(범피스)" 절을 추가하고 GEPA 고유 규격과의 차이를 명시. 에이전트가 `house: bumpis`를 요청받으면 그 규칙으로 쓴다.
4. 유지: 공고문(6-1)과 보도자료는 GEPA 고유 양식이므로 범피스 프로필을 적용하지 않는다(행안부 표준은 "보고서" 서식이다).

## 5. 한계

- 매뉴얼은 pt·mm 등 수치를 일부만 명시한다(글머리 글꼴·크기, 여백). 제목 상자·칩·글상자의 색상 값은 매뉴얼 스크린샷(61p, 14p)에서 눈으로 읽은 근사값이다(연보라 #E6E6F5, 남색 #1F3864, 밑줄 #4472C4, 연파랑 #DFE6F7).
- 범피스 프로그램 자체는 Windows 전용 `.exe`라 이 Mac에서 실행해 실제 출력 hwp를 역분석하지는 못했다. 정확한 값이 필요하면 Windows 한글에서 범피스로 만든 문서 1부를 받아 `scripts/extract-style-map.ts`로 카탈로그화하면 된다.

## 5. 2026-09-16 갱신
사용자 결정으로 범피스 매뉴얼의 글꼴·크기·여백·표 서식이 **기본(GEPA) 프로필의 기본값**이 되었다(`planStyle` in `lib/hwpx/writers/plan.ts`, 아래 여백 10mm in `build.ts`). `house: bumpis`는 표지·절 칩·글상자 등 구조 요소까지 바꾸는 완전 프로필로 남는다. 줄간격은 매뉴얼에 값이 없어 사용자 결정 160%.
