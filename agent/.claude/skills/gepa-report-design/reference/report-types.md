### 절마다 쓸 것 〔박〕

- **추진 배경**
  - 이유·목적·근거·필요성 3개 이내.
  - 10쪽 이내 보고서면 1/2쪽 이내.
  - 우선순위는 법령 근거 > 정책 > 동향 > 미래 예측.
- **현황**
  - 객관적 사실에 출처를 단다.
  - 현 실태(지금 한 시점)와 현황(추이)을 구별한다.
- **문제점·원인**
  - 문제점은 현황의 부정적 결과로 3개 이상 쓴다.
  - 원인은 근본 까닭으로 3개 이상 쓰고 방안과 하나씩 짝지운다.
- **추진 목표 → 방향 → 과제**
  - 셋을 이어지게 쓴다.
  - 과제는 실현 가능하고, 큰 것에서 작은 것 순서로 쓴다.
- **세부 실행 계획**
  - 일정·업무 분장·점검·자원·홍보·평가·위험 관리 가운데 필요한 것만 쓴다.
  - 길면 붙임으로 뺀다.
- **기대 효과**
  - 정량 하나: 문제가 얼마나 풀리나.
  - 정성 하나: 파급 효과.
  - 둘 정도로 짧게 쓴다.
- **행정 사항**
  - 늘어놓지 말고 표나 묶음으로 쓴다.
  - 절 제목을 「기타 사항」「그 밖 사항」으로 달지 않는다.
- **행사 개요**: 성격·목적, 일시·장소·참석자, 주재자(주최·주관), 행사 내용.
- **시간 계획**
  - 시간대·소요 시간·내용·주관자를 표로 쓴다.
  - 시각은 `13:00 ~ 15:00`, 소요는 `120'`.
- **회의 결과**
  - 주요 쟁점 위주로 비슷한 것을 모은다.
  - 발언자는 괄호에 적는다.
  - 이견은 밝히고, 조치할 일을 따로 적는다.

## 2. 제목

- **끝말:** 보고 갈래로 끝낸다(계획·방안·결과·검토·건의·상황…).
- **길이:** 15~20자 안팎, 한 줄. 길어지면 줄이지 말고 부제를 따로 한 줄 단다(`- 부제 -`).
- **「~동향」「~현황」:** 막연한 「~동향」「~현황」만으로 끝내지 않는다. 무엇이 일어났는지 구체적으로 쓴다(「○○ 최근 동향」 ⇒ 「○○, 전국 동시 파업 추진」).
- **약어:** 생소한 약어는 풀어 쓴다.
- **범위:** 본문에 없는 내용을 제목에 넣지 않는다.

## 3. 보고 취지(요약 상자)·보고 핵심

- **보고 취지:** 이 보고를 왜 쓰는지 쓴다. 배경·목적·경과를 짧게 담을 수 있다.
  - 4줄 이내, 문단은 최대 2개, 마침표 없음, 현재 시제.
  - 정기 보고는 생략할 수 있다. 윗선까지 올라가는 보고에는 반드시 단다.
- **보고 핵심:** 긴 보고서는 맨 앞에 3~5줄로 둔다. 대항목 서너 개만 쓰고, 세부는 넣지 않는다.
- **한 장 보고서:** 그 자체로 완결된 보고서다. 단락을 온전히 갖춘다.

## 4. 검토 점검표

### 공통 — 칭찬받는 보고서 6기준 〔요〕

1. **목적:** 목적이 분명하고 전체가 목적에 맞는가.
2. **정확:** 확인을 거쳤는가. 출처가 분명한 자료인가.
3. **간결:** 욕심내 다 담지 않았는가. 너무 압축해 뜻이 비틀리지 않았는가.
4. **쉽게:** 설명 없이 읽히는가. 전문용어·약어는 풀었는가.
5. **완결:** 추가 보고 없이 결정할 수 있는가. 읽는 사람이 「그래서 내가 무엇을 하면 되나」를 묻지 않게 요청 사항이 적혀 있는가.
6. **때:** 알맞은 때인가. 행사 계획은 행사 전날이 늦지 않다.

### 공통 — 흔한 문제 〔요〕

- **틀:** 제목·목차에 내용이 안 드러남. 누가·언제·무슨 목적인지 없음. 논리 순서가 뒤바뀜.
- **충실성:** 표현이 모호함. 자기 판단 없이 견해만 늘어놓음. 논점과 무관한 것을 길게 씀. 같은 말을 바꿔 되풀이함.
- **완결성:** 지나치게 압축함. 배경·경위가 없음. 근거가 부족함. 약어를 설명하지 않음.
- **문제의식:** 원인 분석이 없음. 대안만 늘어놓고 실천 계획이 없음.
- **표기:** 인명·지명·숫자·단위가 틀림.

### 유형별 〔청〕

- **정책 기획:** 목적 / 경과 / 현황·원인(원인의 원인) / 지금까지의 대응 / 유사 사례 / 대안과 쟁점 / 정책 대상 / 효과 / 일정·자원·홍보·성과관리 / 건의 사항
- **조정 과제:** 쟁점 / 대안별 장단점 / 대안을 골랐을 때의 효과 / 건의 / 추진 일정
- **상황·정보:** 적시성 / 육하원칙 / 중요한 것 먼저 / 우리 부서 시각만으로 쓰지 않았는가 / 유관부서 의견을 왜곡 없이 담았는가 / 사진·그래프·통계로 더 잘 보일 수 있지 않은가
- **회의 결과:** 안건별 정리 / 결정사항 요약 / 이견 명시 / 조치 필요사항 명시 / 회의자료·발언록 첨부
- **행사:** 목적 / 일시·장소 / 참석 범위 / 홍보 협의 / 말씀자료 2쪽 이내·보고서 형식 / 핵심 메시지 / 꼭 결정할 사항
