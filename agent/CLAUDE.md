# GEPA 문서 작성 에이전트 작업장

이 디렉터리는 (재)경상북도경제진흥원(GEPA) 공식 문서를 작성하는 에이전트의 작업장이다.
웹앱이 `claude -p`로 이 폴더를 cwd로 하여 실행한다.

규칙
- 모든 산출물은 한국어 공문서 문체(개조식, "~함", "~도모")로 작성한다.
- 문서 본문은 반드시 **GEPA DSL**(`.claude/skills/gepa-dsl/SKILL.md`)로만 출력한다. 마크다운 자유 형식 금지.
- 통계·수치·법령은 출처 없이 만들지 않는다. 조사 노트(`research/notes.md`)와 `sources.json`에 있는 것만 인용한다.
- 고정 문구(참여제한대상, 기타 유의사항 등)는 `{{boilerplate:이름}}` 매크로로만 삽입하고 바꿔 쓰지 않는다.
- 작업 폴더(`--add-dir`로 전달된 프로젝트 폴더) 밖의 파일은 수정하지 않는다.
- Bash는 쓰지 않는다. 파일 읽기/쓰기, 웹검색(WebSearch/WebFetch), 하위 에이전트(Task)만 사용한다.

## 공문서 기본 틀 — 모든 개조식 문서에 적용

사업계획서·공고문·공문·업무보고·결과보고·정산보고는 모두 공문서다(담당자 2026-10-19: "공문서의 기본 틀이 있지 않겠냐", "그런 큰 규칙은 전체 GEPA 문서 엔지니어링에 다 적용되어야 해").
근거는 행정업무운영 편람(각 스킬의 `reference/gov-manual.md`)과 진흥원 보고서 관행이다. 보도자료 본문은 서술형 기사체라 종결·머리말 규칙에서 뺀다(표기 규칙은 같다).

- **말하듯 쓰지 않는다 — 개조식 명사형으로 끝낸다.** "…지원", "…선정", "…달성", "…필요". "모두", "다", "~했다", "~입니다" 같은 말투는 쓰지 않는다(담당자: "계획 6개 점포 모두 지원 이게 뭐냐. 옆집 누나한테 말하냐").
- **줄마다 한 가지만, 결론 먼저.** 머리말 `(키워드)` 는 줄 맨 앞에 한 번만 — 그 줄 안에 다른 괄호를 두지 않는다(날짜 뒤 요일 `(토)` 만 예외). 보충은 쉼표로 잇거나 다음 줄 `※` 로 내린다.
- **번호와 괄호 머리말을 한 줄에 섞지 않는다** — `- (판로 확대) ① 판로지원금` ×. "123이면 123이고 ()면 ()고".
- **나란한 항목은 모두 한 줄로.** 같은 범주의 `-` 줄이 여럿이면 줄마다 한 줄(머리말 포함 약 38자)에 들어가게 뒷말을 줄인다 — 한 줄만 두 줄로 넘치면 보기 흉하다. 나란한 머리말은 띄어쓰기로 글자 폭을 맞춘다: `(판 로 확 대)` `(역 량 강 화)` `(시장 활성화)`.
- **개수만 적지 않는다.** "3개 세부사업", "2개 분야 6개 사업"을 내용 자리에 쓰지 않고 무엇을 해서 무엇을 지원했는지 쓴다. 실적은 목표값과 한 쌍으로 — `※ 목표 6개 점포, 6개 점포 지원으로 100% 달성`.
- **기호와 표기는 편람대로.** 항목 기호 □ → ㅇ → - → ·, 참고는 ※, 항목이 하나뿐이면 기호를 붙이지 않는다. 날짜 `2025. 10. 25.(토)`, 기간 `4. 23.~6. 15.`, 금액 `금80,000,000원(금팔천만원)`, 쌍점 `원장: ○○○`. 화살표로 문장을 줄이지 않는다.
- 내보낼 때 이 규칙을 어긴 줄은 「편람·…」 경고로 잡힌다. 경고가 남지 않게 쓴다.
