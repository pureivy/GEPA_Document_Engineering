# GEPA 문서유형 택소노미 — 사업 라이프사이클 기준

ESG·기업지원팀 2025년 사업 **3종 108건 전수 분석**(2026-09-22).
기존 `gepa-official-doc` 스킬의 택소노미는 **제목 어미**(요청/안내/보고…) 축이다.
이 문서는 그와 직교하는 **서식 × 업무단계** 축을 정의한다. 문서 생성기는 이 축을 써야 한다.
어미는 제목 한 줄을 정할 뿐이지만, 서식은 **문서 전체의 뼈대**를 결정하기 때문이다.

## 서식별 골격

### 공문형 — 도입부 규칙 (실측 54건)

기존 스킬은 "내부문서는 **1항**이 근거 문서번호"라고 규정하지만, 실측은 다르다.

| 수신 | 도입부 | 실측 |
|---|---|---:|
| 외부수신 | `1. 귀 사(기관/도/청)의 무궁한 발전을 기원합니다.` | 24/30 |
| **내부결재** | **번호를 붙이지 않는 리드 문장**으로 근거 인용 | **20/24** |

```
# 내부결재 (S2·S5 표준형)
제 목  「2025년 경북PRIDE기업」신규기업 선정을 위한 정량평가 결과보고

ESG·기업지원팀-1262(2025.05.29.)호 및 1817(2025.07.16.)호와 관련하여   ← 번호 없음
「2025년 경북PRIDE기업」신규기업 선정을 위한 정량평가 결과를 다음과 같이 보고합니다.
1. 평가개요
  가. 평가대상: 요건심사 적격기업 18개사
  나. 평 가 자: 사업담당자 ○○○ 과장
  다. 평가항목: 재무건전성(25), 기술력(25) … 총 100점
      ※ 정량평가 총점 40점으로 환산하여 최종 평가점수에 적용
2. 향후계획
  가. 현장 및 발표평가(2025.7.21. ~ 7.25.)
붙임  정량평가 결과 1식.  끝.
```

**단계별 고정 항목 구성**

| 유형 | 본문 항목 |
|---|---|
| S2 접수결과보고 | `1.접수개요`(모집기간·선정규모·접수방법·접수현황) → `2.향후일정` |
| S5 선정결과보고 | `1.평가개요`(평가대상·평가자·평가항목) → `2.선정결과` → `3.향후계획` |
| S4 평가위원위촉 | `1.인사` → `2.` 평가명·일시·장소·평가내용·평가위원 → `※ 본 공문으로 위촉장 갈음` |
| S6 선정통보 | `1.인사` → `2.선정사실` → `3.` 사업명·지원내용·지원한도·지원기간·기타사항 |
| E4 계약체결 | `1.용역명 2.계약금액 3.계약기간 4.과업내용 5.계약방법 6.계약업체 7.예산과목` |
| C3 정산확정·반납 | `1.인사` → `2.관련근거` → `3.` 집행잔액·발생이자를 **분리 기재** + 반납계좌 |

**다수 수신자 처리** — S4 위촉·S6 통보는 한 파일 안에
`내부결재본 1장 + 수신자별 시행문 N장`이 연속으로 들어간다. 본문은 동일하고 `수 신`만 교체된다.
생성기는 수신자 배열을 받아 N+1장을 렌더링해야 한다.

4. 산출내역: 9,000원 × 12명 = 108,000원

| 필드 | 출현 |
|---|---:|

## 사업유형이 문서 구성에 미치는 차이

| | 세부사업형 | 단건 | 행사성 |
|---|---|---|---|
| 기안 건수 | 71 | 16 | 21 |
| P1 계획(안) | **10건** — 전체계획 1 + 세부사업별 5 + 파생 4 | 1 | 1 |
| S 모집·선정 | **26건** — 세부꼭지마다 공고·접수·평가·위촉·선정 **전 사이클 반복** | 5 | **0** |
| E3 행사서무 | 7 | 2 | **4** (21건 중 19%) |
| C3 정산·반납 | 3 | 1 | **3** (집행잔액·발생이자 **별건 기안**) |

- **세부사업형**의 문서 폭증은 S단계 반복이 원인이다. 세부꼭지 N개면 S1·S2·S3·S4·S5가 각각 N회 발생한다.
  생성기는 "세부사업 목록"을 입력받아 S단계를 루프로 전개해야 한다.
- **행사성**은 S단계가 통째로 없다(공모 없이 위원 위촉으로 구성). 대신 E3(대관·오찬·현수막·다과)과
  C3(잔액·이자 분리 반납)이 비중을 차지한다.
- **단건**은 전 단계를 1회씩만 도는 최소 사이클이다. **표준 레퍼런스로 쓰기 가장 좋다**(16건 = 전형 1세트).

## 기존 스킬 대비 교정·보강 사항

1. **[교정] 내부결재 공문의 근거 인용은 `1.`항이 아니라 번호 없는 리드 문장이다** (20/24).
   `gepa-official-doc` SKILL.md "핵심 규칙" 첫 줄을 수정해야 한다.
2. **[신규] 지출품의형은 공문형과 별개 서식이다.** 현재 스킬에 정의가 없다. 29/108(27%)로 단일 최대 서식군.
3. **[신규] 다수 수신자 = 내부결재본 + 시행문 N장** 렌더링 규칙.
4. **[보강] 접수문서(수신본)를 코퍼스에서 분리**하는 필터가 필요하다.

## 시스템 반영 우선순위

현재 `agent/.claude/skills/`는 사업계획(P1)·모집공고(S1)·보도자료 3종만 커버한다. 나머지 20유형이 공백이다.

| 순위 | 대상 | 근거 |
|---|---|---|
| 1 | **지출품의형 1종**(`gepa-expense-draft`) | 29건 단일 최대. 4필드 고정이라 규칙화 난도 최저, 커버리지 27% 즉시 확보 |
| 2 | **S2·S5 보고형**(`gepa-report-draft`) | 11건. 내부결재 리드문 + `개요→향후계획` 2항 구조로 통일 가능 |
| 3 | **S4·S6 통보형**(`gepa-notice-letter`) | 10건. 수신자 배열 루프 렌더링 |
| 4 | **C1·C2·C3 정산·종료형** | 15건. 붙임 5종 고정세트(정산보고서·결과보고서·정산내역·통장내역·증빙) |
| 5 | 결재보고서형 확장(S3·E1·C1) | P1 스킬의 장 골격을 재사용 |

1~4번까지만 구현해도 108건 중 **65건(60%)**이 자동 생성 범위에 들어온다.
