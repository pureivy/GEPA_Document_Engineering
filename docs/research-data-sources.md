## 3. 붙이는 방식
- 로컬 MCP 서버(`agent/mcp/`, stdio)에 `kosis_query`, `customs_trade(level, code, period)`, `bizinfo_search`, `policy_news_search`, `law_search/law_get`, `datago_call(serviceId, params)`(등록된 서비스 allow-list) 도구를 두고 `claude -p --mcp-config … --strict-mcp-config`로 연결. 키는 `.env.local`(`DATA_GO_KR_KEY`, `KOSIS_KEY`, `LAW_OC`, `BIZINFO_KEY`)에만 둔다.
- 조사 프롬프트: "수치는 위키 → API 도구 → 웹검색 순. API 응답의 기준시점·기관을 `(기관, 연도)`와 `sources.json`의 `api` 필드로 기록."
- WebFetch로 API URL을 직접 부르지 않는다(키 노출, 요약 모델 경유로 손실).
