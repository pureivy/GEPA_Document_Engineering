# GEPA 정산보고서 표준 서식 설계를 위한 실문서 조사 결과

- 조사 대상: `AllAboutGEPA/gepa.db`의 2026년 문서 중 (재)경상북도경제진흥원(GEPA)이 **수탁·수행기관으로서 직접 작성해 제출한** 정산보고서. 함께 붙은 공문 본문(Body)도 확인함.
- 표본 규모
  - 정산 관련 첨부를 가진 문서 455건을 자동 분류했고, 반납 통보·회계정산 의뢰 같은 비대상 6건을 빼면 449건이다(시군별로 나눠 보낸 문서 포함). 이를 같은 사업끼리 묶으면 약 156개 사업군이다.
  - 전문을 정독한 문서는 47개 파일이다(아래 부록 A).
  - 기관이 정해 준 빈 서식 5종도 읽었다: 문경시 정산보고서(서식).hwp, 상주시 사업정산 및 실적보고서(서식).hwpx, 경상북도 실적 및 정산보고서(서식).hwpx ×3.
- 분석 스크립트와 중간 산출물은 scratchpad에 있다: `classify.py`, `classified.json`, `groups_cls.txt`, `d/*.txt`.

## 0. 결론 요약

1. **기본 표준은 「위탁사업 추진실적 및 정산보고서」(V1)로 한다.**
   - 근거 문서는 ESG·기업지원팀-1024(서비스산업 투자유치협의체)다.
   - 이 형식은 다음 세 서식과 표 구조가 같다.
     - 경상북도 「공공기관 위탁·대행사무 출연금 등 실적 및 정산보고서」 서식
     - 시군 위탁 서식(문경·상주 등)
     - 지방보조금 사업추진실적 및 정산보고서
   - 449건 중 37%(167건, 52개 사업군)가 이 계열이다. 6개 팀과 지소에서 모두 쓰여 가장 넓게 쓰이는 형식이다.
2. 나머지는 이 표준에서 **표지·용어·재원 행만 바꾸는 변형**으로 처리할 수 있다.
   - V2 「정 산 보 고」: 마케팅팀형·대행사업형
   - V3 「보조금 정산 보고서」: 민생경제지원팀형
   - V4 지방보조금법 시행규칙 별지 제2·3호 법정서식: 동부지소·포항시 계열
   - V5 「대행사업비 정산보고서」: 동부지소 영천·경주
   - V6 시군 조례 자체서식: 북부지소 안동 별지 제7호, 영주형
   - V7 e나라도움 국고 「보조사업 정산보고서」: 별도 시스템 서식이라 자동생성 대상이 아니다.
3. 숫자 관계는 모든 변형에서 같다.
   - **집행잔액 = 예산(교부)액 − 집행액**
   - **반납액(통장잔액) = 집행잔액 + 이자발생액**(이자는 결산세 공제 후 금액)
   - 집행률 = 집행액 ÷ 예산액
4. 사용자가 넣어야 할 숫자는 다섯 가지뿐이다: 예산 내역(비목별), 지출 거래 목록, 이자, 대행수수료, 사업 실적 수치. 나머지 표는 모두 계산으로 만든다.
5. 문장으로 쓰는 칸은 AI가 초안을 쓸 수 있다: 사업목적, 추진실적, 사업성과, 성과(물) 활용계획, 자체평가, 건의사항, 잔액 발생사유, 변경사유.

### 1.1 기본 표준으로 V1을 권장하는 이유
1. **상위 서식과 일치한다.**
   - 경상북도 서식(일자리팀-13 doc 234, 일자리팀-273 doc 2210, 일자리팀-82 doc 412의 「실적 및 정산보고서(서식).hwpx」)과 시군 서식(ESG-1054 문경 「정산보고서(서식).hwp」)은 모두 이 순서를 따른다.
   - 순서: 표지(사업비 표 + 제출자) → 1. 실적보고서(사업개요·계획대비·성과·자체평가·건의) → 2. 정산보고서(총괄표 → 집행현황 → 세부내역 → 잔액사유 → 변경내역).
2. **가장 넓게 쓰인다.** 6개 팀·지소가 쓰고, 문서 37%, 사업군 33%(52/156)를 차지한다.
3. **다른 변형으로 바꾸기 쉽다.** V1의 표만 있으면 V2·V3·V4·V5·V6의 표를 모두 다시 만들 수 있다. 각 변형은 V1 표의 부분집합이거나 재배치다(§7).
4. **정본으로 지정된 예시가 있다.** ESG-1024는 표지, 사업개요(요약), 정산총괄표, 항목별 집행현황, 집행 세부내역, 변경내역, 잔액사유를 모두 갖췄고, 숫자도 통장거래내역과 맞는 것을 검산했다(§8.1).

> 용어 스위치 `{재원명}`은 사업 성격에 따라 다음 중 하나로 바꾼다: 위탁사업비, 보조금, 지방보조금, 출연금 등, 도비/시군비.

| 성과(물) 활용계획 | ◦ … | [AI] |

**② 계획 대비 추진실적**은 다음 두 형식 중 하나를 쓴다.
- 형식 A(문경·ESG 서식): `구 분 | 추 진 계 획 | 추 진 실 적 | 비고`
- 형식 B(도 서식·법정서식): `시기 | 사 업 계 획 | 시기 | 추 진 실 적 | 사유`
- 두 형식 모두 "계획과 실적이 다르면 사유를 비고(사유)란에 쓴다."

**③ 사업추진성과**
- 서술(◦)로 쓰거나, 지원 실적 표를 둔다. 예: `구분 | 기업명 | 지원개실 | 지원금액 | 비고` + 합계 행(고령 919), `기업명 | 상담건수 | 상담액 | 비고`(CES).

**④ 자체평가**
- 잘된 점, 부족한 점, 문제점, 발전방안을 ◦ 2~4개로 쓴다. [AI]

**⑤ 개선 및 건의사항**
- ◦ 1~3개로 쓴다. [AI]

선택 항목: ⑥ 출연금 등으로 취득한 중요재산 관리 내역(도 서식)
- 열: `취득재산명 | 규격 및 모델명 | 취득년도 | 단가(원) | 수량 | 취득가액(원) | 설치(시설)주소`
- 해당이 없으면 생략하거나 "해당 없음"으로 쓴다.

### 2.2 2. 위탁사업 정산보고서

**① 정산 총괄표**(단위 : 원, %)는 표지 표와 같다.
- `구 분 | 예 산 액 | 지출액(금액·비율) | 집행잔액 | 이자발생액 | (반납액) | 비 고`
- 행: `계 / {재원명}(또는 도비·시군비) / 자부담`
- 서식 각주: "※ 위탁금 교부 시 제출․승인된 사업실행계획서를 기준으로 총사업비, 집행액과 집행잔액을 기록"

**② {재원명} 집행현황**

**②-1 항목별 집행현황**(단위 : 원)은 표준 권장 형식이다. CES 4427과 블루푸드 962의 2단계 구조를 따른다.

| 구분(비목군) | 항목(세목) | 예산액 | 집행액 | 집행잔액 | 비고 |
|---|---|---|---|---|---|
| 사업비 | 행사운영비 | | | | |
| | 민간사업지원금 | | | | |
| | **소계** | Σ | Σ | Σ | |
| 운영비 | 국내여비 / 국외업무여비 / 사무관리비 / 회의비 … | | | | |
| | **소계** | | | | |
| 인건비 | (해당 시) | | | | |
| 수수료 | 대행수수료 | | | | |
| | **소계** | | | | |
| **합계** | | ΣΣ | ΣΣ | ΣΣ | |

- 1단계(비목군만) 표: ESG-1024의 `구 분 | 예산액 | 집행액 | 집행잔액 | 비고` + `사업비 / 운영비 / 수수료 / 합계`가 최소형이다. **합계 행은 맨 아래**에 둔다(ESG-1024). 블루푸드처럼 맨 위 `합계`, 비목군별 `계`를 먼저 두는 배치도 있다.
- 시군 서식(문경·고령) 변형은 **세부사업별 집행현황**이다.
  - 열: `세부사업 | 사업기간(사업일시) | 내 역(세목) | 당초집행계획액 | 실제 집행내역(산출기초 | 집행액) | 잔 액`
  - 산출기초는 "17,643,000 × 1식"처럼 쓴다. 합계 행은 맨 위에 둔다.

**②-2 {재원명} 집행 세부내역**(단위 : 원)
- ESG-1024 표준 열: `인출일자 | 인출액 | 비목 | 내역 | 지급처 | 지출번호 | 지급방법`
- 시군·도 서식 확장 열: `인출일자 | 인출액 | 비목 | 내역 | 지출일자 | 지출액 | 지급처 | 지출번호 | 지급방법`
- 세부사업이 여러 개면 "❍ 세부사업 : ○○"으로 표를 나누고 각 표 끝에 `계` 행을 둔다(세일페스타 1847, CES 4427).
- 지출번호 규칙
  - 같은 결의로 여러 명에게 나눠 지급하면 같은 번호를 반복한다. 예: 심사수당 5명 = 4번.
  - 비목군별 번호(01-01, 02-07)를 쓰는 사례도 있다(블루푸드).
- 지급방법 값: `카드`, `Check카드`, `체크카드`, `계좌이체`, `계좌입금`
- 서식 각주(고정)
  - "※ 내부품의서, 지출결의서, 각종 영수증, 회계장부, 통장 등 세부증빙자료는 별도 편철 제출"
  - "<지급방법별 증빙자료> Check카드: 매출전표 / 계좌입금: 은행입금전표, 세금계산서, …"

**③ 자부담 집행현황**은 자부담이 있을 때만 둔다. 구조는 ②와 같다. GEPA 사업은 거의 모두 "자부담 –"이므로 기본은 생략한다.

**④ 사업 및 소요경비배분 변경내역**(단위 : 원)은 변경사항이 있을 때만 쓴다.
- 열: `세 부 내 용 | 비 목 | 당초예산 | 변경예산 | 주요 변경사유 | 승인여부`
- 각주: "※ 승인여부 : ○○시(경상북도) 승인, 자체변경(내부 결재문서 사본 첨부)으로 구분 기재"
- 변경이 없을 때 실무는 세 가지다: 헤더만 남김(ESG-1024, 4223), "해 당 없 음"(포항 카드 5694), "변경내역 : 없음"(2410). **표준은 "해당 없음" 1행**을 권장한다.

**⑤ {재원명} 집행잔액 발생사유**(단위 : 원)
- ESG-1024 열: `구분 | 세부사업내용 | 예산액 | 지출액 | 집행잔액 | 발생사유`
- 시군·도 서식 열: `구분(단위사업) | 사업(세부)내용 | 예산비목 | 예산액 | 지출액 | 집행잔액 | 발생 사유`
- 행
  - 맨 위는 `합계`다. 비목별 행을 두고, 단위사업이 여럿이면 `소계`를 둔다.
  - ESG-1024와 4223은 **수수료를 빼고** 소계를 냈다(18,360,000 = 20,000,000 − 1,640,000). 수수료는 잔액이 0이기 때문이다.
  - **표준은 수수료 행까지 넣고 잔액 '-'로 표시**한다. 그래야 합계가 총괄표와 같아진다.
- 각주(고정): "※ 발생사유 : 사업계획변경, 사업취소, 지급사유 미발생, 집행잔액, 이자 등 기재"

**⑥ 수익금(이자) 발생 현황 및 집행내역**(도 서식, 선택)
- 열: `세부사업명 | 수익금액 | 수익내역(통장이자) | 비고`
- 실무에서는 대부분 총괄표의 이자발생액 칸으로 대신한다.

**붙임**: 통장 거래내역(사본), 결과보고서. 증빙은 별송한다.

### 2.3 공문 본문(Body)의 정산내역 표: 모든 변형에 공통
본문 "바. 정산내역" 표는 팀 구분 없이 사실상 하나로 통일돼 있다(3534, 293, 817, 152, 180, 1105 확인).

| 교부금(A) | 집행액(B) | 사업비 잔액 (C)=(A)-(B) | 예금이자 (D) | 반납액(통장잔액) (C)+(D) | 비고 |
|---|---|---|---|---|---|
| 20,000,000 | 18,319,100 | 1,680,900 | 10,357 | 1,691,257 | |

- 열 이름 변형: 교부금/교부금액ⓐ/사업예산/사업비(A), 사업비잔액/잔액/집행잔액, 예금이자/이자발생액, 반납액/통장잔액/총 반납금액
- 재원이 둘 이상이면 행을 `합 계 / 도 비 / 시군비`로 둔다(180).
- 본문 골격: 가. 사업명, 나. 사업기간, 다. 사업예산 금○○원(금한글원), 라. 사업내용(지원내용), 마. 추진실적, 바. 정산내역
- 붙임 순서: 정산보고서 → 결과보고서 → 통장내역 → 증빙(별송)

### 3.1 핵심 계산식

| 필드 | 식 | 비고 |
|---|---|---|
| 예산액(재원별·비목별) | [입력] 교부결정액, 변경승인 후 금액 | 합계 = Σ재원 = Σ비목 |
| 집행액(지출액) | Σ 세부내역 인출액. 여입·반납은 음수로 반영 | 지원금 여입은 음수 행(예: `-500,000 사업 포기로 인한 지원금 여입`, 행복카드 1244·포항카드 5694) |
| 집행률(비율) | 집행액 ÷ 예산액 × 100 | §3.2 참조 |
| 집행잔액 | 예산액 − 집행액 | 재원별·비목별 각각 계산하고, 합계 = Σ하위 |
| 이자발생액 | [입력] 사업비 통장 예금이자 합계. 결산세가 있으면 세후 금액 | 블루푸드: 이자 20,353 − 결산세 2,760(법인세 2,510 + 지방세 250) = 17,593 |
| 반납액(=통장잔액) | 집행잔액 + 이자발생액 | 검증: 통장 최종잔액과 같아야 함(ESG-1024: 1,691,257) |
| 재원별 배분(복수 재원) | 재원별 예산비율로 집행액·이자를 나눔 | 체인지업: 도비 30%·시군비 70%(43,100,000:100,600,000), 이자 9,007 → 도비 2,702 / 시군비 6,305 |
| 공통 운영비 안분(통합계좌) | 해당 시군 분담 집행액 = 통합운영비 집행액 × (해당시군 예산 ÷ 전체 예산) | 체인지업 470 각주 원문 그대로 |
| 대행수수료 | [입력] 교부결정·협약 정액 | 관측된 수준: 예산의 4~8%. 예: 1,640,000/20백만, 4,000,000/40백만, 8,000,000/100백만, 120,000,000/3,000백만. 마케팅 397은 "※집행금액의 4.2%", 경북포럼은 "운영수수료 5%"라고 표기 |
| 사업비(계획액) 천원 | 예산액 ÷ 1,000 | 사업개요 표만 천원 단위, 정산표는 원 단위 |
| 재원 비율(%) | 재원 예산 ÷ 총사업비 × 100 | "20,000천원 (100%)", "도비 52,500천원 (30%)" |

### 3.3 자동 검증 규칙(실문서 오류 사례에서 도출)
1. 세부내역 Σ = 항목별 집행액 = 총괄표 지출액.
   - ESG-1024 원문 세부내역의 "12-02 349,800 이희우"는 통장 실제값 329,800과 다르다. 합계 701,600에 맞는 값은 329,800이므로 원문의 오기다.
2. 재원 행 Σ = 계 행.
   - 신중년 6453 원문: 계 83,071,225 / 위탁사업비 83,017,225로 서로 다르다.
3. 항목별 소계 Σ = 합계.
   - 세일페스타 1847 운영비 소계는 예산 22,000,000과 집행 20,673,330이 인건비를 뺀 값이다(11,000,000 + 10,000,000 + α, 10,973,330 + 9,700,000).
   - 그런데 같은 행의 잔액 2,262,560은 인건비 잔액 1,935,890을 포함한 값(26,670 + 300,000 + 1,935,890)이다. 한 행 안에서 포함 범위가 서로 다르다.
   - 동유럽 397 "소계(ⓐ) 25,000,000"은 실제 84,954,794다.
4. 반납액 = 집행잔액 + 이자, 그리고 통장 최종잔액과 같아야 한다.
5. 집행률 ≤ 100.00. 지출액 > 예산액이면 경고한다.
6. 사업기간 안의 날짜인지 확인한다. 정산 직전 대행수수료·회계검토 지출은 기간 밖이어도 허용한다(CES 2026/03/19 회계정산 용역).

**묶음 규칙(항목별 집행현황)**
1. 1단계 비목군 순서를 고정한다: **사업비 → 운영비 → 인건비 → 수수료**. 인건비를 운영비 안에 넣는 사례도 있다(세일페스타, 체인지업은 "간접비 = 기타운영비 + 인건비 + 수수료").
2. 회의비의 위치는 사업마다 다르다.
   - ESG-1024는 회의비(간담회)를 **사업비**로 묶었다. 항목별 사업비 15,977,500 = 행사운영비 15,677,500 + 회의비 300,000.
   - CES는 회의비를 **운영비**로 묶었다.
   - 따라서 **세목 → 비목군 매핑은 사업 예산서(교부결정서) 기준 입력값**으로 두고, 기본값만 사전에서 제안한다.
3. 수수료(대행수수료)는 항상 독립 비목군으로 둔다. 잔액은 보통 0이다.
4. 민생형(V3)은 `직접비(소계ⓐ) / 간접비(소계ⓑ) / 사업비 합계(ⓐ+ⓑ)`의 2분류를 쓴다. 이는 사업비=직접비, 운영비+인건비+수수료=간접비로 대응된다.
5. 마케팅형(V2) `가. 집행 현황`은 `비목 | 항목 | 예산액 | 집행액 | 집행잔액` 형식이다. 예: `사업비 | 행사 운영비 등`, `운영비 | 사무관리비, 여비 등`, `대행수수료 | 대행수수료`. `나. 항목별 세부 집행내역`의 열은 `비목 | 세부내역 | 지출금액 | 지출일자 | 지급처 | 증빙(①②…)`이다. 소계는 `소계(ⓐ)`, `소계(ⓑ)`, `중계(ⓐ+ⓑ)`, `대행수수료(ⓒ)`, `합계(ⓐ+ⓑ+ⓒ)` 순서다.
